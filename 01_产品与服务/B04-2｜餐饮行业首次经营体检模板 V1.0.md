# B04-2｜餐饮行业首次经营体检模板 V1.0

**项目：** 企业经营健康管理\
**适用行业：** 正餐、快餐、火锅、特色餐饮、茶饮及类似门店\
**首批优先场景：** 1–5家门店，同时涉及堂食、团购或外卖\
**文档用途：** 顾问操作规范 + 行业数据指标库 + 老板版报告结构 + 系统开发依据

---

# 一、餐饮体检到底要解决什么

餐饮老板通常不缺乏对自己生意的直觉。

但很多经营问题分散在不同地方：

- 收银系统有营业额
- 美团有核销和结算
- 抖音有团购和推广
- 厨房有采购及损耗
- 财务知道人工、房租和开支
- 老板凭经验判断哪些菜比较赚钱

这些信息没有放在一起，就容易产生几个误区：

**营业额高，不代表真正赚钱。**

**线上订单多，不代表线上渠道盈利。**

**客人少了，不一定是市场不好。**

**生意忙，不代表资金充足。**

所以餐饮首次体检主要回答五个问题：

1. 这家店最近的生意到底是变好还是变差？
2. 客人从哪里来，哪个渠道真正创造收益？
3. 哪些菜品、套餐或时段值得重点经营？
4. 食材、人工、房租和平台费用有没有明显问题？
5. 接下来30天，最值得改善哪几件事？

首次体检不追求一次完成全面经营咨询。

**首先把最重要的问题看清楚。**

---

# 二、适用门店与细分差异

餐饮行业不应只有一套完全相同的指标。

| 门店类型  | 优先分析方向                |
| ----- | --------------------- |
| 正餐、炒菜 | 桌台、翻台、客单价、菜品毛利、平台团购   |
| 火锅、烧烤 | 食材成本、桌均消费、酒水贡献、翻台与损耗  |
| 快餐、小吃 | 订单量、出餐效率、平台费用、单均贡献    |
| 茶饮、咖啡 | 单杯贡献、时段销量、人工效率、复购     |
| 纯外卖   | 平台曝光、转化、客单价、推广费用、履约成本 |
| 多门店餐饮 | 单店表现、同店增长、人员配置、复制能力   |

系统首次选择主模板后，根据实际情况添加细分模块。

例如：

**一家炒菜店有90%客源来自抖音或美团。**

它虽然属于正餐行业，但这次体检必须加强平台经营分析，而不能只看桌台和翻台率。

# 三、首次接触：不要求老板填复杂表格

建议从一段简短访谈开始。

## 3.1 老板访谈12问

### A. 了解生意

**01｜你这家店主要卖什么？**

记录主力菜品、套餐与客单价的大致区间。

**02｜最近三个月，你感觉生意是越来越好、差不多，还是下降了？**

记录老板判断，后续用数据验证。

**03｜现在客人主要从哪里来？**

堂食、抖音、美团、外卖、老客户、转介绍等。

### B. 了解收入与成本

**04｜一个月大概能卖多少钱？**

允许先提供估算，但标记为老板口述。

**05｜每个月最大的几笔开支是什么？**

通常关注食材、人工、房租、平台费用。

**06｜你觉得现在赚钱最多和最少的产品是什么？**

先记录老板直觉，不急着下结论。

### C. 了解经营问题

**07｜最近最头疼的事情是什么？**

**08｜美团、抖音的活动做完以后，你觉得划算吗？**

**09｜有没有出现过很忙但月底没剩下多少钱的情况？**

**10｜员工、厨房或出餐有没有让你比较头疼的问题？**

### D. 了解下一步

**11｜未来三个月有什么计划？**

例如调整价格、装修、招人、开分店。

**12｜如果我们先帮你解决一件事，你最希望解决什么？**

访谈应允许老板使用语音、口述或现有资料回答。

**目标不是让老板填表，而是由顾问把谈话转化为结构化经营信息。**

# 四、第一次应该要哪些数据

## 4.1 第一轮：最小资料包

对于已经使用收银系统和团购平台的企业，优先尝试获得以下资料：

| 资料           | 建议范围    | 为什么需要    |
| ------------ | ------- | -------- |
| 门店营业额记录      | 最近3个月   | 看经营变化    |
| 美团、抖音结算或订单记录 | 最近1–3个月 | 看平台业务和费用 |
| 每月主要成本费用     | 最近1–3个月 | 粗略看盈利情况  |
| 主要菜品、套餐及价格   | 当前      | 理解产品结构   |
| 门店与员工情况      | 当前      | 理解经营规模   |

优先接受：

- Excel导出
- 收银后台截图
- 平台结算截图
- 月度费用记录
- 纸质台账照片
- 老板口述估算

不要求客户必须安装新软件。

## 4.2 第二轮：根据问题补充

### 情况A：销售额下降

进一步要：

- 每日订单数
- 各渠道订单
- 平均客单价
- 重要促销活动
- 去年同期记录（如有）
- 营业天数及停业情况

### 情况B：忙但不赚钱

进一步要：

- 采购成本
- 食材库存
- 人工
- 房租
- 平台佣金
- 商家承担的优惠
- 包装、配送与推广费用

### 情况C：团购活动效果不清楚

进一步要：

- 套餐售价
- 核销订单
- 实际结算
- 商家承担优惠
- 推广费用
- 套餐对应食材成本
- 到店附加消费（如有可靠记录）

### 情况D：准备开分店

进一步要：

- 当前门店真实经营情况
- 装修及设备投入
- 固定成本
- 员工配置
- 成熟店经营水平
- 拟开店租金与投资预算

**每次补充资料必须对应一个明确判断问题。**

原则上优先要求不超过5项关键资料，避免老板产生负担。

# 五、餐饮行业核心指标库

指标分为三级。

## 5.1 一级：绝大部分门店都应该关注

| 指标     | 计算方式          | 回答什么      |
| ------ | ------------- | --------- |
| 营业额    | 同一期间有效销售收入    | 最近卖了多少钱   |
| 日均营业额  | 营业额÷实际营业天数    | 生意水平有什么变化 |
| 订单量    | 有效交易订单数量      | 客人下单是否减少  |
| 客单价    | 对应销售收入÷有效订单数  | 每单平均消费多少  |
| 渠道收入占比 | 某渠道收入÷总收入     | 主要靠哪里卖货   |
| 经营收支概况 | 经营收入与相关成本费用比较 | 大致是否有经营结余 |

注意：客单价必须说明按人次、订单还是桌次计算，不能混用。

## 5.2 二级：数据允许时深入

| 指标      | 计算方式           | 经营价值        |
| ------- | -------------- | ----------- |
| 食材成本率   | 食材实际耗用成本÷对应收入  | 判断采购、损耗与定价  |
| 人工成本率   | 员工人工成本÷营业收入    | 观察人员费用压力    |
| 平台费用率   | 对应平台费用÷对应平台收入  | 观察平台经营成本    |
| 单均贡献    | 单笔实收收入减相关变动成本  | 判断每单是否有经营贡献 |
| 菜品贡献    | 菜品收入减对应直接变动成本  | 判断值得推广的菜品   |
| 门店经营结余  | 门店收入减可归属经营成本费用 | 判断门店经营状况    |
| 盈亏平衡营业额 | 固定成本÷贡献毛利率     | 估计需要达到的销售规模 |

**重要限制：**

食材实际耗用不等于当月采购额。

如果有期初库存、期末库存及相关调整记录，应按统一口径核算耗用；资料不全时只能做估算。

门店经营结余也不等于经过完整财务核算的企业净利润。

如果物业自有、老板自己在店里工作，应在需要做长期盈利或开店决策时另外考虑物业与老板劳动的经济成本。

## 5.3 三级：行业专业增强指标

按需选用：

- 堂食翻台率
- 桌均消费
- 单位营业面积销售额
- 每员工销售额
- 菜品销量与贡献矩阵
- 套餐核销后附加消费
- 堂食和团购客户复购
- 时段销售与人工配置
- 食材损耗率
- 新老门店对比
- 开店投资回收期

不要求所有客户计算所有指标。

# 六、重点模块一：堂食、美团、抖音到底谁赚钱

这是首批餐饮体检最值得专业化的模块之一。

## 6.1 必须区分四种金额

**第一种：菜单原价。**

例如一个套餐标价多少钱。

**第二种：顾客实际支付。**

顾客使用优惠券、折扣后，真正支付多少钱。

**第三种：商家实际应得收入。**

需要结合平台补贴、退款、核销及结算规则确认。

**第四种：扣除相关成本和费用后剩余的经营贡献。**

涉及食材、包装、佣金、商家承担的优惠、推广及其他相关变动费用。

**不能把四种金额当作一回事。**

尤其要避免：

- 抖音团购券销售与实际核销重复计入
- 堂食收银金额与平台核销收入重复计入
- 把平台结算金额当作全部销售收入
- 把已经扣除的佣金、商家优惠再次扣减
- 忽略退款、未核销与跨期结算
- 把平台给消费者的补贴直接当作商家成本

团购购买、核销、退款和结算可能发生在不同日期，必须确定统一业务口径并做核对。

## 6.2 建议形成《渠道经营对比表》

| 项目       | 堂食      | 美团  | 抖音  |
| -------- | ------- | --- | --- |
| 有效订单数    | 待填      | 待填  | 待填  |
| 实际销售收入   | 待填      | 待填  | 待填  |
| 对应食材成本   | 待填      | 待填  | 待填  |
| 平台与履约费用  | 不适用或实际值 | 待填  | 待填  |
| 商家承担推广费用 | 待填      | 待填  | 待填  |
| 其他直接变动成本 | 待填      | 待填  | 待填  |
| 估算渠道贡献   | 待计算     | 待计算 | 待计算 |

部分统一发生的人工、房租和水电不直接强行分摊。

先比较可归属的经营贡献，再根据具体决策需要做完整成本分析。

## 6.3 老板版表达

不说：

“平台综合ROI和贡献毛利结构异常。”

直接说：

> **美团卖了不少，但我们发现扣掉套餐成本和相关费用后，剩下的钱可能不多。建议先查清楚最畅销的三个套餐，再决定要不要继续投广告。**

如果费用不齐全：

> **目前只能看到美团卖了多少，还不能确定真正赚了多少。**

# 七、重点模块二：菜品、套餐到底值不值得卖

先看两个问题：

**卖得多不多？**

**每卖一份能留下多少经营贡献？**

可以形成四类产品：

| 类型      | 经营特征   | 可能行动      |
| ------- | ------ | --------- |
| 卖得多，贡献高 | 核心经营产品 | 保持质量，适当推广 |
| 卖得多，贡献低 | 流量产品   | 检查成本和搭配销售 |
| 卖得少，贡献高 | 有潜力产品  | 小范围测试推广   |
| 卖得少，贡献低 | 低效产品   | 重新评估或调整   |

这只是分析分类，不是自动决策规则。

例如某个低贡献套餐可能承担引流作用，必须同时看顾客附加消费和复购，不能因为单品贡献低就直接建议下架。

需要数据：

- 菜品或套餐销量
- 实际销售价格
- 食材耗用成本
- 商家优惠
- 相关包装或履约费用

资料不足时，最多形成初步判断。

# 八、重点模块三：这家店每个月到底有没有经营结余

首次体检不必替代正式财务核算，但应该尽量帮助老板搞清楚门店主要收支。

建议整理：

**门店经营收入**

减去：

- 食材等直接成本
- 员工人工
- 房租或场地使用成本
- 水电燃气
- 平台及推广费用
- 包装和配送
- 其他主要经营开支

形成：

**门店经营结余估算**

不能混淆：

- 经营结余
- 经营现金流
- 净利润
- 老板可以实际拿走的钱

设备折旧、装修摊销、税费、借款利息、自有物业成本及业主劳动成本等，是否纳入必须明确。

对于准备扩张的企业，应进一步形成完整、可比较的单店经济模型。

# 九、体检报告：老板版餐饮专用结构

## 第1页｜这家店现在怎么样

**一句话经营判断：**

[根据实际数据和访谈填写]

**目前比较好的地方：**

[填写]

**最值得注意的地方：**

[填写]

**值得关注的机会：**

[填写；无可靠机会则不强行填写]

**未来30天先做的事情：**

1. [行动一]
2. [行动二]
3. [行动三]

## 第2页｜这家店的钱从哪里来，又花到哪里去

只选本次最有价值的经营数据。

建议展示：

**图一：最近3个月营业额变化**

**图二：堂食、美团、抖音经营情况对比**

如果数据允许，再展示：

**图三：主要成本和费用结构**

图表下面必须有一句话解释经营意义。

例如：

> 抖音贡献了较多订单，但相关费用也较高，下一步需要重点核算套餐是否划算。

## 第3页｜我们发现的问题和机会

原则上只讲1–3件重要事情。

每件事使用：

**我们看到什么**

**可能意味着什么**

**建议怎么做**

不直接向老板展示内部证据等级编码。

## 第4页｜以后我们重点帮你盯什么

按企业实际情况选择3–5项：

- 每周销售额
- 堂食和线上订单
- 高销量套餐贡献
- 食材成本变化
- 主要平台活动
- 差评或重要客户反馈
- 行业与本地经营机会

明确哪些已经具备数据来源，哪些仍需建立。

## 专业增强页（可选）

根据实际问题添加：

- 菜品贡献分析
- 平台套餐专项
- 单店盈亏分析
- 多门店对比
- 开新店初步测算

建议每次首次体检只选择最相关的1–2项增强模块。

# 十、餐饮经营监测规则

经营监测必须在企业授权和数据来源明确后启用。

## 10.1 建议初始监测表

| 监测事项    | 建议频率 | 参考触发逻辑       | 数据来源  |
| ------- | ---- | ------------ | ----- |
| 营业额     | 每周   | 对比可比周持续下降    | 收银数据  |
| 平台订单    | 每周   | 某平台订单明显变化    | 平台后台  |
| 套餐贡献    | 每月   | 主要套餐贡献持续下降   | 销售及成本 |
| 食材成本    | 每月   | 成本变化超出可解释范围  | 采购及库存 |
| 差评      | 每周   | 出现重大或重复性投诉   | 评价记录  |
| 重要经营日期  | 按事件  | 租约、证照等即将到期   | 企业档案  |
| 政策和商业机会 | 每周   | 出现与企业匹配的有效信息 | 公开来源  |

触发条件应结合企业经营历史、营业日、节假日和促销变化制定。

不能统一规定“营业额下降10%就是经营异常”。

## 10.2 三级提醒

### 普通变化

进入每周简报，不单独打扰老板。

### 值得关注

发送简短提醒，说明变化及可能原因。

### 需要尽快处理

发现较明确、影响较大的风险信号时，由顾问核实后提醒。

例如：

> 最近两周，某平台实际订单明显减少，而门店营业时间和活动安排基本没有变化。建议先查看平台曝光、推广投放及套餐核销情况。

## 10.3 缺失数据处理

当某个指标未更新：

不得默认显示为正常。

应显示：

**本周没有拿到新的数据，暂时不能判断。**

# 十一、30天行动计划生成规则

首次报告原则上最多建议3项核心行动。

每项应具备：

- 具体动作
- 经营目的
- 负责人
- 完成时间
- 顾问支持
- 完成标准

例如：

| 行动              | 负责人   | 时间    | 完成标准         |
| --------------- | ----- | ----- | ------------ |
| 核算三款主要团购套餐的实际贡献 | 店长+顾问 | 第1周   | 得到可核对的套餐贡献表  |
| 对比最近三个月食材耗用变化   | 采购/财务 | 第2周   | 识别主要成本变化来源   |
| 小范围测试调整一款低贡献套餐  | 老板+运营 | 第3–4周 | 比较调整前后的订单和贡献 |

以上为通用示例，不是对任何真实门店已作出的诊断。

如果数据不足，首要行动可以是补充关键资料，而不是直接要求企业调整经营。

# 十二、WorkBuddy与系统实现要求

## 12.1 行业识别

系统记录：

- 主行业：餐饮
- 细分行业
- 门店数量
- 主要经营渠道
- 老板当前主诉
- 数据可用程度
- 选择的专项分析模块

## 12.2 数据接收

优先支持：

- Excel / CSV
- 收银数据
- 美团、抖音后台导出
- 截图与照片
- 微信文字和语音整理结果（在授权范围内）

不能将不同平台的订单和结算数据简单直接相加。

## 12.3 计算模块

优先实现：

- 营业额趋势
- 订单与客单价
- 渠道收入结构
- 平台费用
- 菜品贡献
- 主要收支
- 同期与环比比较

每次计算保留：

- 公式
- 数据来源
- 时间范围
- 统计口径
- 计算状态

## 12.4 AI分析模块

AI可以：

- 建议重点分析方向
- 识别异常线索
- 解释指标变化
- 整理可能原因
- 生成定向追问
- 形成初步行动建议
- 起草老板版报告

AI不得：

- 虚构营业额
- 猜测食材成本
- 使用未经确认的行业平均值
- 在数据不全时宣称某平台亏损
- 将相关性直接写成因果关系
- 直接替企业决定价格、人员或投资调整

## 12.5 顾问审核

正式报告发送前，顾问必须确认：

- 收入数据没有明显重复计算
- 关键成本口径一致
- 不把平台结算额与营业额混淆
- 不把采购额直接等同食材耗用
- 重要发现有依据
- 建议符合企业实际情况
- 所有后续监测都有明确的数据来源或待建立标记

# 十三、第一阶段实施边界

建议餐饮模板MVP先聚焦三个真正容易形成价值的能力。

### 能力一：看营业额和订单变化

用已有收银和平台记录，帮助老板看清楚最近生意的变化。

### 能力二：算主要平台套餐是否划算

选取最重要的2–3个套餐，做有依据的收入、成本和费用拆解。

### 能力三：形成后续经营提醒

根据企业资料条件，建立3–5项经营监测事项和30天行动计划。

第一阶段不急于开发：

- 全套餐饮ERP
- 完整菜品成本核算系统
- 自动控制采购
- 自动修改平台价格
- 自动操作商家后台
- 复杂财务系统
- 不受监督的自动经营决策

# 十四、试运营验收标准

选取真实餐饮企业试点时，重点检验：

1. 老板是否愿意完成基础访谈。
2. 能否取得至少一类可靠经营数据。
3. 系统能否识别堂食、团购与外卖的收入差异。
4. 是否能够追溯重要计算指标。
5. 能否提出至少一项具体、有依据的经营发现，或明确说明无法判断。
6. 老板是否理解报告结论。
7. 老板是否愿意执行建议的下一步。
8. 能否建立至少一项可持续更新的经营监测。
9. 完成一次体检实际消耗多少顾问人工。
10. 客户是否觉得值得持续付费。

建议额外记录：

- 顾问实际工时
- 数据清理耗时
- AI节省的工作
- 报告修改次数
- 老板实际阅读和反馈
- 30天后行动完成情况

这些结果将直接用于决定行业模板是否具备规模化交付能力。

# 十六、核心交付原则

餐饮行业专业体检，不是让老板看更多指标。

而是帮老板回答：

> **到底哪里赚钱？**

> **到底哪里花钱太多？**

> **生意为什么变化？**

> **这个月先改善哪件事？**

> **以后哪些事情需要有人持续帮我盯着？**

**后台做专业分析，老板只需要看到看得懂、信得过、能执行的结论。**
