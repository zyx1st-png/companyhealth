# D02｜企业经营健康管理首批客户招募与销售转化方案 V1.1

**2026-10-13新客转化规则**：取消99元30天付费体验；新客M线以**免费M-L0（7–14天）→直接199/399/1299元起月费**为主路径。P高级专项继续独立按C08/B08的P-L0初筛和合同开展。首30天会员与专项各42.5小时，需控制免费容量。

## 一、谁适合首批接触

优先挑选老板或实际经营负责人愿意交流、日常需要信息筛选/资料整理/宣传推广/客户沟通，且愿意在适当阶段为有价值的持续服务付费的企业。首批3–5家M-L0候选并不等于3–5家会付费的会员。对只寻求大型免费诊断、要求秘密抓取业务聊天、长时间无限咨询的对象暂缓。

## 二、获客渠道优先级

1. **熟人经营者与历史合作伙伴转介绍**：可信进入，但不能把人情认可视为付款意愿。
2. **协会合作自愿介绍**：可向愿意参加的会员说明试点，公益服务、协会成员数据与独立商业合同隔离；不暗示协会担保。
3. **财税、门店、商业服务伙伴**：相互推荐，仅获得客户明确允许的信息；利益关联必要时披露。
4. **针对性走访/朋友圈内容**：以实际解决经营小问题的案例吸引自愿报名，避免大范围扫街与昂贵投放。

## 三、统一漏斗（阶段不能跳级）

| 阶段 | 证据 | 不得冒充 |
|---|---|---|
| 线索/转介绍 | 可能符合目标的企业，已获允许联系 | 付费意向 |
| 有效接触 | 负责人实际参与，愿意了解免费L0 | 合同 |
| 启动M-L0 | 知情同意、定范围及起止时间 | 已成交会员 |
| 交付与反馈 | 外部机会简报、一次轻量事务、定向跟进；实际阅读/应用记录 | 购买需求强证据 |
| 书面推荐套餐 | 199/399/1299之一及权益，客户有明确下一步 | 订单 |
| 正式付款 | 真实合同/收款证据与日期 | 月度稳定续费 |
| 真实使用与续费 | 已按约定履约、到期再购买的证据 | 意向延长 |

## 四、首次沟通和体验

第一轮不向客户推销系统、Agent、AIGC，不要求企业披露详细利润和完整账本；问业务类型、目标客群、近期事项和哪些公开行业变化可能与其有关。由客户选择是否接收有限信息及材料服务；最小资料建档、外部机会简报、7–14天跟进、一次轻量快办详见D06。

**示意邀请**：我们准备为少数本地企业做7–14天免费经营支持体验，先聊聊你的业务，帮你留意可能相关的信息，整理一份小简报，再免费帮你完成一次简单的办公或宣传需求。之后如果确实有帮助，再考虑是否需要199/399/1299元起的月度服务，不需要先交体验费。

## 五、正式月费如何推荐

| 客户实际需求 | 优先推荐 | 理由 |
|---|---|---|
| 主要需要外部信息、事项提醒、有限日常事务 | 199元 | 日常快办2/周或定制处理1/周，其他权益按B01 |
| 需要持续经营问诊、周报/简析及较多事务 | 399元 | 日常快办4/周或定制处理2/周，经营支持更深 |
| 需要顾问月会、深度分析、重要事项参与 | 1299元起 | 日常快办6/周或定制处理3/周；深度服务需核工时 |
| 只需要明确边界的大型项目 | B08高级专项 | 不强迫购买会员、不把P01塞进399会员 |

**一次定制处理可替代两次日常快办；可混用但两列不相加。** 具体日常办公、推广、数据、经营咨询的可交付成果见C09/B06。不能无条件承诺复杂任务、无限修改或保证营收提升。

## 六、反馈与转化节奏

免费开始时说明结束日和收费权益；第7–14天询问“哪些信息真正被使用、你以后希望我们持续关注/处理什么”。若有使用需求则推荐一个匹配套餐；如无付费意愿则礼貌结束服务，不能把免费的周报无限延期。客户有明确重大问题和采购能力时另走P-L0。

## 七、商业数据与失败原因

至少记录匿名线索数、完成初谈数、已同意M-L0数、按期交付数、有效反馈数、主动提出需求数、正式推荐/报价数、实际付费数、后续续费数；分人情支持/真实业务需求/只喜欢免费内容/专项型需求/价格不符。记录每家访谈、公共信息核验、定制简报、轻事务交付、人工审核与跟进分钟，判断免费获客效率。

## 八、签约、合规与终止

免费阶段也须明确范围、数据用途与停止联系方式；收费与正式数据处理须满足G00/G10、G03/G05/G06和主体核验。所有金额均为待验证试价；旧G01《99元体验服务协议》退出新客路径。停止免费服务或未成交不意味可以保留客户敏感信息作为默认训练/营销数据。

## 九、对外统一定位与30秒介绍（恢复旧D02 §2）

第一次接触不主动推销AI Agent、模型、系统或全面诊断；先说明实际能够做什么。

> 我们为中小企业做一项长期经营支持服务，有点像企业的经营家庭医生。平时可以帮你关注经营信息和政策机会，也能协助处理宣传、客户沟通、办公资料、简单经营分析等日常事务。先提供7–14天免费轻量体验，看看哪些内容真正对你有帮助，之后是否购买月费完全由你决定。

**一句话**：每月花几百元，让企业有一个持续了解业务、留意机会、协助处理小事的外部经营助手。

不承诺保利润、保证获得补贴、保证引流、自动抓取企业系统、无限响应和持牌财税法律结论。对外避免“M-L0”“P-L0”“B06”等内部代号；合作内部仍按D06/C08管理。

## 十、首次五问与一次相关能力演示（恢复旧D02 §7）

1. 企业目前主要做什么、常见客户是谁？
2. 最近最让你关注的一件经营问题是什么？
3. 平时有哪些查信息、写资料、整理数据或宣传事务缺乏人手？
4. 如果定期关注企业外部机会或经营变化，你最希望先关注什么？
5. 如果接下来7–14天的小规模免费服务确实有帮助，你是否愿意了解正式月费服务？**这是意向，不代表签约**。

第一次交流控制在约15–30分钟（M-L0后续深访另议），**只演示一个与客户当下需求相关的成果**：餐饮可演示已标注模拟的活动成本简表；商贸可演示经授权的报价比较模板；物业可演示清晰的客户通知。不得用未经许可的真实客户资料演示。不要展示一整套复杂系统架构迫使企业学习使用技术。

## 十一、渠道A–E执行细节（恢复旧D02 §4）

| 渠道 | 建议行动 | 容易出现的风险 |
|---|---|---|
| A 熟人/经营者转介绍 | 先取得联系许可，针对一个具体经营困扰约简短沟通 | 熟人夸赞不等于购买或使用 |
| B 商协会自愿介绍 | 以实际需求/公益分享邀请少数企业自愿报名；协会公共服务与商业服务分账 | 不能挪用名单、暗示协会背书或强制会员购买 |
| C 财税/代账/企业服务机构 | 明确双方各自服务职责、资料权限及潜在利益关系 | 不未经同意转交企业财务/联系人信息 |
| D 针对性企业走访 | 预约负责人、围绕一项实际问题而非系统销售作交流 | 获客人时过高，干扰正常营业 |
| E 朋友圈/公众号/短内容 | 用匿名化、已授权或标明模拟的小案例展示“能帮忙解决什么” | 不制造真实案例、客户评价或承诺收益 |

优先A与B低成本试验；C–E按实际接触效率补充。每渠道记录接触数、已获同意数、L0启动、正式报价、实际实收及人时，样本太少不宣称渠道已经成熟。

## 十二、首批沟通与常见疑问（恢复旧D02 §6、§9）

**熟人微信**：最近试做面向中小企业的经营支持服务，平时能协助宣传、材料、信息筛选和经营事项。现在找几家企业免费试做7–14天，不用先提交账本，愿意聊聊你最近最关心的一个问题吗？

**协会合作沟通**：计划邀请少量愿意自愿参与的会员企业体验公开信息机会简报和一次实际的简单事务处理，服务由项目方独立执行。协会不承担商业签约或保证付费转化，结论只汇报脱敏汇总。

| 老板疑问 | 直接答法 |
|---|---|
| “你们到底做什么？” | 帮企业留意相关经营信息、整理常用材料、处理小型问题；具体能交付哪些事在C09说明。 |
| “我自己用AI不行吗？” | 可以。我们的区别是长期了解业务、按实际问题筛选资料、必要审核和跟进结果；并非销售模型账号。 |
| “我没有经营数据。” | 免费阶段先用自愿提供的基础情况与公开信息；没有数据不会编造经营指标。 |
| “资料要给你们吗？” | 不要求一次提交敏感资料；需要时先说明用途与AI处理边界，取得必要授权，拒绝也可以选择公开信息服务。 |
| “免费都能做什么？” | 7–14天轻沟通、公开机会简报、少量定向跟进与简单问答、一次日常快办；不含完整体检与复杂专项。 |
| “能保证赚钱或拿补贴吗？” | 不能保证结果，只承诺约定范围内的分析、支持、材料与跟进。 |
| “必须转399元吗？” | 不用，体验到期自主选择199/399/1299元起或退出；没有自动续费和99元抵扣。 |
| “问一句要扣一次制作吗？” | 约定的日常问答与周期简报不扣制作任务额度；新增独立材料成果，事前说明一次轻量或复杂。 |

## 十三、四周获客与转化节奏（恢复旧D02 §10、§12，改为新路径）

- **第1周**：准备服务说明、匿名线索表、合法告知与演示样稿；向少数明确愿意沟通的企业开始免费L0，先建立信任，不要求付款。
- **第2周**：安排第7–14天真实使用回访，反馈已发送机会是否相关、一次快办有没有用、是否主动提新要求；可以推荐正式套餐，也可以退出。
- **第3周**：对已签并真实付款客户履约；有明确专项经营问题则另走P-L0和独立报价。无真实付费不能写“已转正”。
- **第4周**：核对客企转化、渠道成本、使用率、首次交付工时与客户投诉，再按V02做30天复盘；不假定已有续费。

## 十四、最小客户跟进台账与漏斗分母（恢复旧D02 §14–§15）

无需先开发CRM。用受控、可撤回联系的内部表格，至少记录：匿名客户ID、行业、渠道、负责人/联系许可、首次沟通日、最关心问题、L0开始/结束、实际交付与使用反馈、下一次客户同意的跟进、正式月费档位与报价、签署状态、实收日期/金额、是否到续期及真实续费、拒付原因、获客/服务人工分钟、客户撤回和资料删除到期日。私人联系人、合同原文不能上Git。

**正式转化率** = 已完成并到达决策节点的M-L0中真实付款正式月费的客户数 ÷ 同一批次已完成且到决策节点M-L0客户数。客户仍在免费期或尚未到决策节点，单独标记，不混入拒绝分母。

**渠道现金获客成本** = 本渠道可归属的实际获客现金支出 ÷ 本渠道实际首次付款正式会员数；**另记人工获客成本**，不能混算。3–5家小样本只做方向证据，不作为稳定转化率或获客成本预测。

## 十五、失败风险与销售验收（恢复旧D02 §16–§19）

1. 免费吸引只想占用大量制作/咨询的人群 → 停在D06限定边界，超出范围必须先告知。
2. 399或1299每周复杂任务集中提交，超出容量 → 事前排期，先遵已有合同、暂停新增；H03情景检验且记录真实人时。
3. 合作方以为包办政策申报/专业认证 → 仅解释公开信息与协助准备常规材料；持牌事项转专业服务。
4. 所有线索依赖熟人且不付款 → 分渠道统计，不能把人情支持当成交。
5. 只喜欢一次免费文案，不关心持续经营服务 → 按失败证据复盘，调整客户定位和交付价值。
6. 客户真实授权缺失、AI资料越界、未到期资料保留 → 暂停处理并执行G11/G05/G10。

首批验收至少有可复核的：有效初谈、具体需求、合法同意、完成L0与一次快办、主动使用、真实报价、真实付款（若有）、人工成本以及拒绝原因。**只有免费转正式付款，才能证明支付行为；没有付款时应如实记录。**
