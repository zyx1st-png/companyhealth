# D02｜企业经营健康管理首批客户招募与销售转化方案 V1.1

**2026-10-13新客转化规则**：取消99元30天付费体验；新客M线以**免费M-L0（7–14天）→直接199/399/1299元起月费**为主路径。P高级专项继续独立按C08/B08的P-L0初筛和合同开展。首30天会员与专项各42.5小时，需控制免费容量。

## 一、谁适合首批接触

优先挑选老板或实际经营负责人愿意交流、日常需要信息筛选/资料整理/宣传推广/客户沟通，且愿意在适当阶段为有价值的持续服务付费的企业。首批3–5家M-L0候选并不等于3–5家会付费的会员。对只寻求大型免费诊断、要求秘密抓取业务聊天、长时间无限咨询的对象暂缓。

## 二、获客渠道优先级

1. **熟人经营者与历史合作伙伴转介绍**：可信进入，但不能把人情认可视为付款意愿。
2. **协会合作自愿介绍**：可向愿意参加的会员说明试点，公益服务、协会成员数据与独立商业合同隔离；不暗示协会担保。
3. **财税、门店、商业服务伙伴**：相互推荐，仅获得客户明确允许的信息；利益关联必要时披露。
4. **针对性走访/朋友圈内容**：以实际解决经营小问题的案例吸引自愿报名，避免大范围扫街与昂贵投放。

| 阶段 | 证据 | 不得冒充 |

| 有效接触 | 负责人实际参与，愿意了解免费L0 | 合同 |
| 启动M-L0 | 知情同意、定范围及起止时间 | 已成交会员 |
| 交付与反馈 | 外部机会简报、一次轻量事务、定向跟进；实际阅读/应用记录 | 购买需求强证据 |
| 书面推荐套餐 | 199/399/1299之一及权益，客户有明确下一步 | 订单 |
| 正式付款 | 真实合同/收款证据与日期 | 月度稳定续费 |
| 真实使用与续费 | 已按约定履约、到期再购买的证据 | 意向延长 |

## 四、首次沟通和体验

第一轮不向客户推销系统、Agent、AIGC，不要求企业披露详细利润和完整账本；问业务类型、目标客群、近期事项和哪些公开行业变化可能与其有关。由客户选择是否接收有限信息及材料服务；最小资料建档、外部机会简报、7–14天跟进、一次轻量快办详见D06。

**示意邀请**：我们准备为少数本地企业做7–14天免费经营支持体验，先聊聊你的业务，帮你留意可能相关的信息，整理一份小简报，再免费帮你完成一次简单的办公或宣传需求。之后如果确实有帮助，再考虑是否需要199/399/1299元起的月度服务，不需要先交体验费。

## 五、正式月费如何推荐

| 客户实际需求 | 优先推荐 | 理由 |
|---|---|---|
| 主要需要外部信息、事项提醒、有限日常事务 | 199元 | 日常快办3/周或定制处理1/周，其他权益按B01 |
| 需要持续经营问诊、周报/简析及较多事务 | 399元 | 日常快办6/周或定制处理2/周，经营支持更深 |
| 需要顾问月会、深度分析、重要事项参与 | 1299元起 | 日常快办9/周或定制处理3/周；深度服务需核工时 |

**一次定制处理可替代三次日常快办；可混用但两列不相加。** 具体日常办公、推广、数据、经营咨询的可交付成果见C09/B06。不能无条件承诺复杂任务、无限修改或保证营收提升。

## 六、反馈与转化节奏

免费开始时说明结束日和收费权益；第7–14天询问“哪些信息真正被使用、你以后希望我们持续关注/处理什么”。若有使用需求则推荐一个匹配套餐；如无付费意愿则礼貌结束服务，不能把免费的周报无限延期。客户有明确重大问题和采购能力时另走P-L0。

## 七、商业数据与失败原因

至少记录匿名线索数、完成初谈数、已同意M-L0数、按期交付数、有效反馈数、主动提出需求数、正式推荐/报价数、实际付费数、后续续费数；分人情支持/真实业务需求/只喜欢免费内容/专项型需求/价格不符。记录每家访谈、公共信息核验、定制简报、轻事务交付、人工审核与跟进分钟，判断免费获客效率。

## 八、签约、合规与终止

免费阶段也须明确范围、数据用途与停止联系方式；收费与正式数据处理须满足G00/G10、G03/G05/G06和主体核验。所有金额均为待验证试价；旧G01《99元体验服务协议》退出新客路径。停止免费服务或未成交不意味可以保留客户敏感信息作为默认训练/营销数据。
