## 四、保密提示

- 本仓库为**私有仓库**，不得公开或 fork 到公开位置。
- `C03-INT 协会共建合作定位与商业边界备忘录` 标注为**内部使用**，不随 C03 对外发送。
- 未来**不要**把任何真实试点企业的经营数据、合同、联系人信息提交到本仓库（见 `.gitignore`）；示例报告中的企业与数据均为虚构或公开信息模拟。

## 五、更新约定

1. 新文档沿用编号体系命名：`<编号>｜<标题> V<版本>.md`，放在 `创业文档/`。
2. 小改直接改原文件，由 git 记录历史；大版本升级可新建 `V1.1` 文件，并在上方「版本」表登记取代关系。
3. 提交信息写清改了什么，例如：`B01: 顾问版调价至 1599 元`。
