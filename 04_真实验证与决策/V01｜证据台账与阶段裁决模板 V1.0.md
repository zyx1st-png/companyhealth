# V01｜真实证据台账与阶段裁决模板 V1.0

**仅为空白操作模板。严禁提交客户可识别信息、真实经营原始数据、合同照片、微信原文、票据明细到GitHub。** 具体凭证保存在经授权的业务空间，只在这里保存脱敏证据ID/复核摘要。

## A. 试点启动条件（执行前核对，不预勾选）

- [ ] 已确认合法的收款/开票/签约主体与服务边界
- [ ] 体验协议、专项合同、授权书、AI告知和删除规则经必要律师/财税审定
- [ ] 能证明数据隔离、保密、备份及异常恢复实际可用
- [ ] 明确是否允许接收客户B/C类资料；无授权则仅匿名/公开模拟
- [ ] 已选首批2–3家候选行业和分批启动时间
- [ ] 服务权益、首次响应、转化抵扣条款与对外材料一致
- [ ] 明确工作时间、重要咨询超配处理及安全事件暂停责任人

**证据强度**：E0内部构想；E1客户表达；E2付费体验；E3正式购买/专项签约并收款；E4续费/实际使用；E5跨客户跨周期可复现。会员与专项证据应分轨说明，不能把“专项单次签约”直接推断为订阅留存。证据等级不等于统计置信度。
