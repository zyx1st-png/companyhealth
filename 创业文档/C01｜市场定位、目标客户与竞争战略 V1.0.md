# C01｜市场定位、目标客户与竞争战略 V1.0

**项目：** 企业经营健康管理\
**定位：** 中小企业的经营家庭医生\
**文档性质：** 创业商业战略\
**研究市场：** 凯里及黔东南起步，未来视验证结果扩展\
**阶段：** 商业模式尚待验证

---

# 一、核心战略判断

企业经营健康管理不是单纯的AI经营软件，也不是传统项目制咨询。

本项目希望填补的需求是：

> 中小企业虽然拥有各类经营工具和外部服务机构，却可能缺少一个能够长期了解企业、综合判断问题并持续跟进的服务角色。

因此，产品核心不是“提供更多信息”，而是：

**持续了解企业 → 发现重要事项 → 协助分析与处理 → 跟进结果 → 更新企业认知。**

但这一需求是否足够强烈、是否愿意形成持续付费关系，尚未经过真实客户验证。

本文件的目标是明确最有可能购买这项服务的客户，以及如何与已有替代方案竞争。

---

# 二、首先区分三种客户角色

项目此前的部分讨论将企业客户、机构合作方和最终服务对象混在一起。

未来应明确区分：

| 角色  | 定义           | 示例               |
| --- | ------------ | ---------------- |
| 购买方 | 谁为服务付款       | 企业老板、商协会、集团公司    |
| 决策方 | 谁批准采购或续费     | 老板、协会负责人、采购部门    |
| 使用方 | 谁实际提出问题、接收服务 | 企业负责人、门店经营者、管理人员 |

这三个角色可能相同，也可能不同。

例如：

**直接会员模式：**

一家商贸企业购买399元会员，老板自己使用服务。

**商协会推荐模式：**

商会推荐，会员企业自行购买，本项目直接服务企业。

**商协会采购模式：**

商协会统一采购企业经营支持服务，成员企业接受服务。

**集团企业模式：**

总部采购，旗下多家门店或子公司使用。

四种情况对应不同的销售周期、合同结构、交付责任和产品形态。

不能用同一套价格和合同处理。

# 三、市场需求假设

## 3.1 企业并不一定缺少软件

常见中小企业可能已经使用：

- 微信和企业微信
- Excel
- 收银及进销存系统
- 财务和代账服务
- 美团、抖音等平台后台
- 政府政策服务平台
- 通用AI工具

所以，销售时不宜假定客户缺少经营数据或AI能力。

更合理的需求假设是：

**企业已经有不少工具和信息，但缺少持续整合、解释和行动跟进。**

## 3.2 四个潜在付费动机

### 动机一：减少老板个人工作负担

老板经常需要亲自处理经营分析、材料、政策查询和业务协调。

潜在购买理由：

> 有人长期帮我处理一些值得做、但不值得专门雇人的经营事务。

### 动机二：减少经营问题被忽略的概率

例如客户订单下降、合同到期、应收超期和平台费用异常。

潜在购买理由：

> 有人持续帮我盯着，不要等问题很严重了才发现。

### 动机三：获得外部判断

老板可能拥有大量一线经验，却缺少不同角度的分析与对照。

潜在购买理由：

> 遇到重要问题时，有人帮我把事情想清楚。

### 动机四：获得可信资源

需要法务、财税、数字化或合作资源时，企业不一定知道找谁。

潜在购买理由：

> 我不需要你什么都会，但希望你帮我找对人，并继续跟进。

## 3.3 需要谨慎验证的判断

不能直接假设：

- 企业愿意为上述需求每月付费。
- 管理问题越多，付费意愿就越高。
- 老板不懂AI，就一定需要外部服务。
- 数据越丰富的企业，越愿意交出数据。
- 服务内容越多，客户越觉得划算。

这些都需要后续客户研究验证。

# 四、目标客户细分

建议形成四类目标客户，不在创业初期全部同等投入。

## S1｜具有一定规模的中小经营企业

**建议作为主要最终服务对象。**

典型特征：

- 有持续经营收入
- 具有多个人员或业务环节
- 老板仍亲自参与大量管理工作
- 缺乏专门的经营分析岗位
- 有实际经营数据或管理记录
- 经常发生需要跟进的经营事项

优先行业可考虑：

- 商贸批发
- 经销与供应链
- 餐饮及多门店
- 本地生活服务
- 工程和项目型企业

主要购买人：

企业负责人。

主要购买动机：

省时间、看问题、处理事情。

适合产品：

199元及399元会员，具体根据服务需求确定。

**主要疑问：**

为什么不直接使用免费的AI工具或由现有员工完成？

必须用真实服务效果回答。

---

## S2｜成长型企业与多门店经营主体

**建议作为高价值客户候选。**

典型特征：

- 拥有多个门店或业务单元
- 业务正在扩张
- 信息分散在多个系统
- 老板需要判断重要投资和经营问题
- 管理复杂度明显高于单一门店

主要购买人：

老板、总经理或经营管理负责人。

主要购买动机：

经营透明、跨门店对比、管理效率及决策支持。

适合产品：

顾问版或明确范围的专项服务。

**主要风险：**

这类企业需求可能迅速发展为定制咨询或系统集成，超出1299元起的常规会员权益。

因此，应先判断是否适合长期会员，不默认用低价承接复杂项目。

---

## S3｜商协会、园区及企业服务机构

**建议作为优先研究的机构客户。**

这类客户可能有两种购买动机。

### 一种是增加会员服务价值

希望提供：

- 经营健康体检
- 企业问题梳理
- 个性化信息服务
- 惠企政策支持
- 企业需求与资源对接
- 服务效果反馈

### 另一种是提升企业服务管理能力

希望更好地了解：

- 会员企业普遍关心什么
- 哪些服务需求最多
- 哪些事项需要专业人员处理
- 哪些服务真正产生使用和反馈

这里存在潜在机构采购价值。

但协会统一购买不等于企业愿意持续使用，也不等于协会有预算。

**核心验证问题：机构是否真正有采购预算、采购权限和持续服务目标。**

机构采购后，成员企业信息不能未经授权直接汇总或提供给采购方。

---

## S4｜较大规模企业或集团总部

**建议作为探索性客户，不作为低价会员的默认服务对象。**

潜在需求：

- 跨门店经营监测
- 专项经营分析
- 企业内部AI工作流
- 管理信息整理
- 企业知识库
- 部门协作及重要事项跟进

可能购买人：

总经理、运营部门、数字化部门或采购部门。

竞争者：

内部团队、信息系统供应商、专业咨询机构和行业AI服务商。

可能适合：

专项顾问合同、数字化建设项目或限定范围的管理服务。

对于已有专业团队的企业，不能只靠“比人工便宜”作为销售理由。

必须证明外部服务具有独特的信息整合、专业判断或交付效率优势。

# 五、初期不建议同时服务所有客群

为了避免定位过宽，建议采用：

## 主要服务对象

有真实管理问题、具备一定经营规模、没有完整专业支持团队的中小企业。

## 优先研究的机构合作方

商协会、园区及具有企业服务需求的组织。

## 高价值机会客户

多门店、成长型企业以及需要专项数字化或经营支持的规模企业。

这三类客户可以同时存在，但必须建立不同的产品边界。

**不能把原本面向399元会员的交付标准直接用于复杂机构项目。**

# 六、直接销售和机构合作的商业模式区别

## 模式A｜企业直接购买会员

企业自行付费并接受服务。

主要收入：

199、399和1299元起的会员费，以及另行购买的专项服务。

优势：

- 客户需求直接
- 产品反馈直接
- 定价和交付较容易控制
- 与长期经营档案关系一致

挑战：

- 必须逐家建立信任
- 单客户收入较低
- 初次体检成本较高
- 客户可能不习惯订阅制

## 模式B｜机构推荐，企业自行购买

商协会、园区或合作机构向会员企业介绍服务。

最终企业自主决定是否付费。

优势：

- 可以降低初次接触成本
- 容易形成特定行业客户群
- 服务关系仍直接建立在企业与本项目之间

挑战：

- 合作方未必持续推荐
- 推荐不等于购买
- 合作收益与责任需要明确
- 必须防止客户因人情而参与

## 模式C｜机构统一购买服务

机构为一定数量的成员企业支付服务费用。

优势：

- 可能形成较大的单笔合同
- 便于集中开展企业建档和体检
- 可以提供机构层面的服务使用统计

挑战：

- 决策周期可能更长
- 涉及采购预算和审批
- 企业未必主动使用
- 个性化交付可能集中增加人工
- 机构与企业的数据访问权限不同

**必须分别定义机构采购内容与成员企业个人服务权益。**

不能把机构采购金额简单除以成员企业数量，就当作每家399元会员成立。

## 模式D｜规模企业定制采购

企业直接购买专项能力。

例如：

经营信息整合、门店经营分析、企业AI工作流或经营顾问服务。

优势：

- 单项目合同金额可能较高
- 更容易获得明确业务目标
- 可以产生专业案例

挑战：

- 售前与采购复杂
- 交付要求更高
- 数据与系统安全要求更严格
- 单人模式可能缺少持续项目容量

适合作为机会型业务，而非创业初期的全部收入支柱。

# 七、竞争格局：不能再把免费工具理解成低水平竞争者

本项目至少面对六类竞争或替代方案。

| 替代方案        | 已有价值           | 我们必须提供的额外价值      |
| ----------- | -------------- | ---------------- |
| 老板自己使用AI    | 问答、材料、初步分析     | 企业历史认知、持续跟进与人工责任 |
| 平台AI经营助手    | 平台数据、经营建议、自动化  | 跨系统经营理解及平台之外的协助  |
| 政府公共服务平台    | 政策、资金、订单、培训等信息 | 个性化判断、后续服务与执行协助  |
| 代账及财税机构     | 长期合作、专业财税服务    | 非财税的综合经营问题识别     |
| 企业现有管理人员    | 熟悉企业、可以直接执行    | 外部视角、专业方法及按需能力   |
| 专业咨询和数字化服务商 | 深度专业交付         | 持续关注、低门槛进入和资源协调  |

竞争分析不能笼统写“其他工具都没有持续服务”。

部分平台已经具备AI助手、定期经营报告或自动化处理能力。

所以，本项目的差异不能建立在“别人不会生成周报”这个假设上。

# 八、建议建立的差异化能力

## 差异一：跨业务场景理解企业

不局限于单一平台数据。

根据客户授权和可获得的信息，理解：

- 客户
- 产品
- 渠道
- 收入
- 成本
- 回款
- 管理事项
- 外部机会

但不能声称已经自动接入全部系统。

## 差异二：经营问题持续跟进

对于企业：

**一次发现问题不等于解决问题。**

通过经营档案、待办、问诊、监测和复盘，形成跨时间的连续服务。

需要通过真实客户验证这种连续性是否产生更高的使用价值。

## 差异三：人工判断与服务责任

AI提供辅助分析。

顾问负责：

- 事实核对
- 判断解释
- 行动建议
- 服务协调
- 正式交付

对于复杂问题，可以转介专业机构。

这并不意味着顾问能够保证经营结果。

## 差异四：行业专业模块

针对不同企业采用不同指标及问题结构。

例如：

餐饮关注平台和门店贡献。

商贸关注客户、应收和库存。

项目企业关注合同、成本和回款。

行业能力需要通过真实案例验证，而不是仅靠模板数量。

## 差异五：本地资源与关系

在凯里及黔东南，面对面沟通、行业关系和本地资源可能有助于服务交付。

但本地资源只有在能够提供可信、有效的解决方案时才构成优势。

熟人关系本身不是永久竞争壁垒。

---

# 九、最重要的产品差异：从信息输出转向行动闭环

建议把竞争优势定义为：

**不是提供了多少条建议，而是哪些问题得到了持续处理。**

服务应形成：

发现 → 核实 → 建议 → 确认行动 → 跟进 → 记录结果。

例如：

一家商贸企业发现某客户采购下降。

普通报表可能显示：

“客户采购同比减少30%。”

本项目如果具备客户经营上下文，可以进一步：

- 确认是否属于季节性或主动减少低毛利订单
- 向老板说明可能的经营意义
- 协助制定回访问题
- 在约定时间跟进是否完成
- 根据新信息修正原判断

这种连续服务才是需要验证的核心差异。

并非所有客户都愿意接受如此深入的跟进，所以仍需建立客户偏好和服务边界。

# 十、付费决策：客户为什么现在购买

不要把购买动机理解为“客户觉得AI先进”。

更可能推动购买的触发事件包括：

### 企业端

- 经营收入或客户出现明显变化
- 老板近期工作负担增加
- 开始使用新平台或渠道
- 准备扩张或开新门店
- 需要整理内部管理流程
- 刚经历一次经营问题或损失

### 机构端

- 希望推出新的会员服务
- 正在建设企业服务体系
- 有明确的企业培训或管理服务预算
- 需要了解成员企业的真实服务需求
- 希望提高现有服务项目的参与度和可见成果

以上是潜在购买触发因素，并非已验证的当地采购规律。

---

# 十一、客户采购决策需要什么证据

不同购买方要求不同。

| 客户类型     | 最有说服力的证据               |
| -------- | ---------------------- |
| 中小企业老板   | 能看懂、真有用的企业经营案例         |
| 多门店企业负责人 | 实际经营指标与管理改进案例          |
| 商协会负责人   | 成员企业参与、使用及满意反馈         |
| 机构采购负责人  | 合同交付清单、服务标准、数据管理和供应商资料 |
| 规模企业     | 专业能力、保密机制、交付质量及可控风险    |

因此不能只准备一份商业计划书对所有客户销售。

但也不需要立刻制作五套完全不同的产品。

建议保留统一的项目定位和服务底座，按采购角色调整说明重点。

# 十二、市场规模如何测算

本项目暂不直接使用“全国有多少中小企业 × 会员费”作为实际市场空间。

经营主体数量并不等于有支付能力、能被触达、愿意长期购买的企业数量。

建议建立自下而上的市场测算模型。

## 12.1 市场规模分层

**潜在总市场：**

理论上可能需要经营支持服务的企业及组织。

**可服务市场：**

在服务区域、行业能力、经营需求和价格条件下，有可能购买的企业。

**可获得市场：**

通过当前获客渠道与交付容量，实际可能接触、成交并稳定服务的企业。

## 12.2 建议估算公式

可触达潜在客户数：

目标区域符合条件的企业数 × 可接触比例。

年度付费客户数：

可触达客户数 × 实际成交率 × 适用的服务周期系数。

年度会员收入：

各档实际服务月份 × 对应实际月费。

机构合作收入和专项项目收入分别测算。

不能把尚未取得的政府服务项目、机构采购预算和潜在转介绍作为已确定收入。

## 12.3 当前缺失的数据

- 凯里及黔东南真正符合目标条件的企业数量
- 各行业企业结构
- 直接客户付费意愿
- 商协会及机构实际预算
- 不同客户的采购周期
- 99元体验到会员的转化
- 各套餐的真实续费情况
- 客户单月服务成本

这些数据必须在未来的市场调研与试运营中逐步补充。

# 十三、市场进入的建议顺序

## 第一个方向：验证直接企业服务需求

优先验证：

- 企业愿不愿意付99元体验
- 哪项持续服务最有价值
- 是否愿意购买199元或399元会员
- 是否愿意持续提供必要信息
- 是否会主动产生经营问诊

目的：证明最终服务使用者确实需要该产品。

## 第二个方向：验证机构合作采购

重点区分：

- 机构愿意推荐但不付费
- 机构愿意共同组织活动
- 机构愿意采购部分服务
- 机构愿意长期签约

每一种情况对应不同的商业价值。

## 第三个方向：探索成长型企业专项需求

当某类客户明确需要经营分析或数字化项目时，评估是否形成独立的高价值服务。

避免把重型项目塞进低价会员套餐。

---

# 十四、市场战略的主要风险

## 14.1 定位过宽

什么企业都服务，最后无法形成行业专业能力。

## 14.2 低价导致价值感知不足

客户可能把经营家庭医生误解成廉价文员或AI代操作。

## 14.3 免费AI替代持续增强

如果主要价值只是周报、政策摘要和普通材料制作，容易被免费的AI工具覆盖。

## 14.4 机构合作形成伪需求

协会负责人认可项目，不代表成员企业会使用，更不代表愿意续费。

## 14.5 规模企业需求超出服务能力

较大企业可能要求复杂数据整合、定制系统和严格服务水平承诺。

## 14.6 客户数据成为合作障碍

企业不愿提供内部数据，可能削弱经营分析能力。

需要从低敏感、最小必要的数据开始，而不是强制全面接入。

## 14.7 增值服务缺乏稳定性

不能假设长期会员一定带来足够多的专项项目。

# 十五、当前战略选择建议

基于现有产品与启动条件，建议：

### 主线一：企业经营健康会员

保留：

- 经营档案
- 经营简报
- 经营问诊
- 经营雷达
- 行动跟进
- 资源推荐

以中小企业为主要服务对象。

### 主线二：机构企业服务合作

研究向商协会、园区和企业服务组织提供：

- 企业经营体检
- 会员经营支持
- 企业服务需求整理
- 资源推荐与专业转介
- 经授权的汇总分析

机构合作不默认意味着机构购买全部会员服务。

### 主线三：高价值专项服务

对于规模较大或需求较复杂的企业，提供：

- 专项经营分析
- 数字化项目
- AI工作流
- 其他经过范围确认的服务

采用专项报价，不受低价会员默认权益覆盖。

**三条业务共用企业经营健康档案和顾问服务方法，但购买方、合同、价格及交付范围应分别设计。**

# 十六、当前还未确定的战略问题

1. 商协会主要是销售渠道，还是直接采购客户？
2. 企业会员收入与增值服务收入，哪一项才应作为长期业务的盈利支柱？
3. 是否集中做两类行业，还是保持更多行业的通用服务能力？
4. 顾问服务是主要产品，还是未来AI平台的早期获客入口？
5. 是否值得向规模企业提供独立于会员体系的更高价专项产品？

以上问题不应由商业计划书主观写死，应通过商业模式设计与市场验证逐步裁决。

# 十七、C01结论

**这个项目不应该与所有AI经营软件正面竞争。**

也不应该依靠“政策资讯更多、材料更便宜、报告更漂亮”构建主要优势。

更有潜力的定位是：

> **为缺少完整经营支持团队的企业，提供一个长期了解业务、能够处理日常问题、持续发现重要变化并跟进结果的外部经营支持关系。**

对于机构客户，则应回答另一问题：

> **这种服务能否帮助机构更有效地服务其成员企业，而且形成可验证的服务成果？**

前者验证真实服务需求。

后者验证机构合作商业价值。

只有把这两种需求分别跑通，才能判断“经营家庭医生”究竟更适合作为直接订阅服务，还是更适合作为机构采购的企业服务基础设施。
