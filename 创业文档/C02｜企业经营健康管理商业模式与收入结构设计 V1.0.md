# C02｜企业经营健康管理商业模式与收入结构设计 V1.0

**项目：** 企业经营健康管理\
**适用阶段：** 创业筹备与首批客户商业验证\
**经营模式：** 创始人主导 + AI辅助 + 外部专业服务协同\
**研究对象：** 会员订阅、专项服务及协会渠道\
**文档性质：** 内部商业分析，不是对外收益承诺

---

# 一、商业模式的核心定位

企业经营健康管理希望通过持续了解企业经营状况，提供日常经营支持、问题分析、机会发现和资源协调服务。

商业模式不是单纯销售AI软件，也不是传统一次性经营咨询。

其主要设计为：

**以长期经营服务关系为基础，以AI降低部分交付成本，以专业能力解决实际问题，以专项服务承接超出会员范围的需求。**

但必须明确：

持续服务关系是否能够转化成稳定付费、客户能否长期留存，以及专项需求是否真实存在，目前尚未获得足够实际数据支持。

不能将商业模式设计当作商业模式已经成立。

---

# 二、建立三个收入模块

## 模块A｜企业长期会员收入

当前产品价格：

| 套餐  |     月费 | 主要价值           |
| --- | -----: | -------------- |
| 基础版 |   199元 | 持续信息、机会与重要事项关注 |
| 标准版 |   399元 | 经营分析、问诊及适当材料支持 |
| 顾问版 | 1299元起 | 更深入的持续经营顾问服务   |

**定位：经常性收入的基础。**

长期会员的商业意义包括：

- 与企业持续保持服务联系
- 积累经过授权的企业经营档案
- 建立后续经营监测能力
- 提高持续需求响应效率
- 通过服务记录判断客户真实价值
- 为合理的专项服务提供需求入口

会员收入具有持续性潜力，但只有客户真正续费才能形成稳定收入。

## 模块B｜独立专项服务收入

例如：

- 专项经营诊断：现行参考起价2000元
- AI与数字化项目：现行参考起价3000元
- 重型经营材料与完整项目方案
- 企业经营管理专项分析
- 专业服务资源协调

**定位：承担高工作量、特殊能力和较高价值的服务需求。**

专项服务必须有独立范围与定价。

不能因为客户购买399元会员，就默认提供完整的数字化建设、长期驻场或大型管理咨询。

## 模块C｜企业服务渠道与生态合作

包括：

- 商协会转介
- 现有企业关系
- 财税与专业机构转介
- 企业之间推荐
- 专业服务联合项目

**定位：降低客户接触成本、提高信任效率，以及扩大可用专业资源。**

当前与协会的讨论属于合作意向。

协会不计入确定收入，也不将其会员数量直接计入已获得销售线索。

# 三、一个客户如何产生收入

建议将客户生命周期分成四个阶段。

## 第一阶段：发现需求

客户通过熟人、协会、专业机构或直接接触了解到本项目。

需要判断：

- 是否存在真实经营问题
- 是否有持续支持需求
- 是否愿意沟通并提供必要信息
- 是否能够合理交付
- 是否有付费可能

此时一般尚无收入。

获客沟通会产生人工成本。

## 第二阶段：99元30天体验

目前已经确定：

**99元为30天体验服务费，不是可退意向金。**

体验完成后，企业不因没有购买正式会员而要求无条件退还服务费；未履约或法律规定的其他情形按协议及适用规则处理。

体验结束后不自动续费。

正式购买会员时，已经支付的99元全额抵扣会员费。

该阶段的目的主要是验证需求、服务使用和真实购买意愿。

## 第三阶段：长期会员

正式会员按对应套餐支付费用。

企业获得符合套餐权益的持续服务。

这是经常性收入的主要来源。

## 第四阶段：专项服务

当企业存在超出会员服务范围的明确需求时，可以另行评估专项项目。

并非所有会员都会购买专项服务。

不能把专项收入作为必然发生的会员增购。

---

# 四、99元体验的真实经济意义

这是现有商业设计中必须重点评估的一环。

根据D01现行试运营工时假设：

**每家企业30天体验约需要5.5–12.5小时人工，不包含获客、重大专项及异常资料修复。**

内部按照每小时80元计算创始人劳动经济成本：

| 项目         |   低工时 |    高工时 |
| ---------- | ----: | -----: |
| 体验期人工      | 5.5小时 | 12.5小时 |
| 对应劳动经济成本   |  440元 |  1000元 |
| 体验收款       |   99元 |    99元 |
| 未考虑工具费时的差额 | -341元 |  -901元 |

说明：

**99元体验不是依靠当期收费覆盖完整交付成本的产品。**

它更接近一种低门槛获客和服务验证机制。

## 特别重要：99元的抵扣不能重复计算

以399元标准版为例：

企业先支付99元体验费。

体验结束后决定正式购买标准版，首月再支付300元。

则这两个服务阶段累计收款：

**99 + 300 = 399元。**

不能将其当成：

**99元体验收入 + 399元完整会员收入 = 498元。**

如果继续全额抵扣，体验阶段实际上没有给最终转化客户带来额外的净收款，而是提前收到了一部分会员费用。

因此，首次体检人工投入必须依靠未来会员服务贡献或其他合理收入逐渐回收。

具体会计收入确认、发票及税务处理需按照合同和适用规则处理；上面仅讨论整个客户关系的商业现金流。

# 五、三档会员的单位经济模型

采用此前D03设定的假设：

**创始人劳动经济价值：80元/小时。**

下表中的人工成本不是创业初期实际支付的工资。

软件和AI增量使用成本为假设值，实际应核实是否与固定订阅支出重复计算。

| 指标          |      基础版 |      标准版 |      顾问版 |
| ----------- | -------: | -------: | -------: |
| 月收入         |     199元 |     399元 |    1299元 |
| 月人工时间假设     |      1小时 |      3小时 |      8小时 |
| 人工经济成本      |      80元 |     240元 |     640元 |
| 增量工具成本      |      12元 |      25元 |      60元 |
| **月单位经济贡献** | **107元** | **134元** | **599元** |

单位经济贡献：

**会员收入－增量工具成本－创始人劳动经济成本。**

不包含：

- 初次体检和建档成本
- 客户获取成本
- 公司固定经营支出
- 税费
- 专业外包
- 异常售后和退款
- 其他实际风险成本

因此不能把单位贡献理解为最终净利润。

## 当前模型最大的敏感性

标准版399元，假设每月仅使用3小时人工。

但是它包括每周简报、月度经营简析、经营问诊、材料支持及季度面对面服务等权益。

如果这些工作实际超过3小时，经济贡献会快速减少。

### 标准版不同人工工时的经济表现

| 月人工 | 月单位经济贡献 |
| --- | ------: |
| 2小时 |    214元 |
| 3小时 |    134元 |
| 4小时 |     54元 |
| 5小时 |    -26元 |
| 6小时 |   -106元 |

工具成本固定按25元/月估算。

**当标准版月人工达到5小时，即使不分摊公司固定费用，按照80元/小时的经济成本口径，单客户也已经出现负贡献。**

这不是说实际现金账户立即亏损，而是意味着创始人投入的时间无法获得假设中的经济回报。

当前399元标准版必须被列为重点验证对象。

# 六、首次建档成本与客户留存

假设会员后续每月按原模型稳定使用服务。

初次体验人工投入为5.5–12.5小时。

对于体验后转正的客户，由于99元全额抵扣会员费，不能把该款当作额外收回的初次投入。

## 六个月会员关系的简化模型

以下假设客户连续支付6个月会员费，人工工时维持原假设。

不包含固定费用、获客投入和体验阶段工具成本。

| 会员  | 6个月常规单位贡献 |    减去初期人工后 |
| --- | --------: | ---------: |
| 基础版 |      642元 |  -358至202元 |
| 标准版 |      804元 |  -196至364元 |
| 顾问版 |     3594元 | 2594至3154元 |

这说明：

**低价会员是否具有商业价值，很大程度上依赖客户留存时间和首次服务效率。**

以标准版为例：

134元/月的经济贡献，需要约3.3–7.5个正常付费服务月，才能仅覆盖440–1000元的初次人工投入。

还没有计入公司的固定开支和销售获客成本。

如果大量客户只购买一个月就退出，模式很难形成健康的经济回报。

因此，客户留存应与正式付费转化具有同等重要性。

# 七、公司的两种利润口径必须分开

## 7.1 现金经营口径

因为创业者初期不从项目支取生活费，也暂不发放固定工资，所以现金模型关注：

**客户实际收款－实际工具及外包费用－公司日常现金支出。**

它回答：

> 项目的现金能否维持运转？

## 7.2 经济利润口径

需要进一步考虑：

**创始人实际投入时间的经济价值。**

它回答：

> 这项生意能否提供合理的劳动回报，并在未来雇用人员后继续成立？

这两个口径不能混用。

项目现金为正，不代表商业模式足以聘请同等能力的服务人员。

# 八、月度经营情景测算

根据现有D03-A预算：

**公司每月计划现金支出约1298元。**

假设不额外租办公室，不支付创始人工资。

这1298元暂作为固定经营预算，其中包含一定交通和推广支出。

按会员类型另外计入增量工具成本。

## 情景一｜5家标准版客户

| 项目         |        每月 |
| ---------- | --------: |
| 会员收入       |     1995元 |
| 增量工具成本     |      125元 |
| 创始人服务时间    |      15小时 |
| 创始人劳动经济成本  |     1200元 |
| 固定经营预算     |     1298元 |
| **现金经营结余** |  **572元** |
| **经济利润**   | **-628元** |

这一情景下，即使不考虑创始人工资，项目也已经能够覆盖假设中的日常现金支出。

但按劳动经济成本计算，仍然亏损。

## 情景二｜8家不同档位会员

假设：

- 基础版2家
- 标准版5家
- 顾问版1家

| 项目         |        每月 |
| ---------- | --------: |

| 固定经营预算     |     1298元 |
| **现金经营结余** | **2185元** |
| **经济利润**   |  **185元** |

这一情景下，经济利润刚刚为正。

但没有计入首次体检、获客、流失客户及新增专项交付等负担。

因此不能宣布已经实现稳定盈利。

## 情景三｜12家不同档位会员

假设：

- 基础版2家
- 标准版8家
- 顾问版2家

| 项目         |        每月 |

| 会员收入       |     6188元 |
| 增量工具成本     |      344元 |

# 九、专项服务是否可能成为重要利润来源？

当前商业模型不能只依赖大量399元会员。

专项经营分析和数字化服务，可能有更高的单笔收入空间。

但专项业务也存在两个问题：

**第一，项目需求不一定持续出现。**

**第二，复杂项目可能消耗大量人工或外部专业费用。**

因此应独立测算，不能只比较收费金额。

## 专项服务案例：3000元项目

假设某项AI工作流或经营分析项目：

- 收费3000元
- 创始人实际投入12小时
- 外部专业支持800元
- 额外工具与交付费用100元

按80元/小时计算：

人工经济成本为960元。

则项目经济贡献：

**3000－960－800－100＝1140元。**

但如果同样项目需要创始人投入25小时：

人工经济成本上升为2000元。

项目经济贡献下降到：

**100元。**

两种情况可能对应完全相同的合同价格。

因此，专项服务必须在报价前确认：

- 服务目标
- 项目范围
- 具体交付物
- 预计工作量
- 外部专业投入
- 修改次数
- 验收条件
- 付款节点

不能把“高客单价”直接等同于“高利润”。

# 十、三种长期商业模式的比较

## 模式A｜纯会员订阅

客户每月缴费，获得约定服务。

### 优势

- 经常性收入
- 客户关系稳定时容易安排服务
- 经营档案可以长期复用
- 产品逐步标准化

### 主要挑战

- 单客户收入有限
- 初次建档成本较高
- 客户大量使用服务时人工负担增加
- 必须具备较长留存周期

**成立前提：服务效率足够高，客户真正愿意长期续费。**

## 模式B｜会员关系 + 专项增值服务

会员保持长期联系，复杂事项单独付费。

### 优势

- 会员服务提供持续接触机会
- 深度需求可以独立报价
- 不要求全部工作都塞入399元
- 较容易兼容企业经营咨询和数字化项目

### 主要挑战

- 专项项目收入不稳定
- 客户可能只需要一次专项服务
- 低价会员也不能无限投入
- 必须防止为了促成专项服务而夸大企业问题

**这是目前优先验证的商业模式，但不应预先假设增值成交率。**

## 模式C｜机构或规模企业年度服务合同

例如规模企业希望采购一定周期的经营支持或专项服务组合。

### 优势

- 合同金额有可能高于普通会员
- 服务范围可以按企业情况定制
- 采购方更容易明确年度服务目标

### 主要挑战

- 采购流程和付款周期可能更复杂
- 数据与质量要求更高
- 可能要求专属人员或系统集成
- 单人交付风险较大

**建议作为机会型业务探索，不纳入首期收入基线。**

# 十一、协会渠道应怎样纳入商业模型？

已确认的个人合作倾向：

**愿意参与或牵头协会经营服务板块，同时保留独立公司、产品与商业收益。**

内部公益投入：

**每周约2–4小时。**

按每月4周、80元/小时的机会成本计算：

- 公益时间：约8–16小时/月
- 对应劳动经济价值：640–1280元/月

这不意味着协会应当支付对应金额。

它意味着：

**协会合作是一项真实的时间投入，应独立评估价值。**

## 协会可能创造的四种收益

### 关系收益

认识更多真实经营企业与负责人。

### 需求收益

更早接触企业真实经营困难，帮助完善产品。

### 专业协同收益

更容易与财税、法务、AI及其他企业服务方建立合作。

### 商业收益

由自愿了解服务的企业转化为正式付费客户。

上述四项必须分别评估。

不能把参加协会会议、认识企业和获得付费客户当成同一件事。

## 不应做的预测

假设协会有700家会员，所以按照10%转化率预计获得70家客户。

这种算法没有依据。

至少需要先确认：

- 真实有效企业数量
- 愿意了解服务的人数
- 有明确经营需求的人数
- 企业同意转介的人数
- 实际体验人数
- 正式付费人数
- 客户留存和服务工时

## 协会合作与商业转化的边界

公益板块可以创造公共会员服务价值。

独立公司可以向自愿购买的企业提供专业服务。

但不得利用协会职务实施强制转介、排他推荐或不透明的利益安排。

涉及本人商业利益的协会内部决策，应按照适用规则披露并处理利益冲突。

# 十二、年度付费是否应该重点推广？

现有基础版年度价格为1980元。

相当于每月：

**165元。**

相比199元按月支付，年费折算价格降低34元/月。

按基础版1小时人工、12元增量工具成本测算：

**年付基础版每月单位经济贡献约73元。**

相比月付方案的107元，有明显下降。

因此：

年度预收款可以改善短期现金流，并可能提高客户关系的确定性。

但年度合同也带来未来持续交付义务。

在真实续费情况和服务成本尚不明确时，建议不要过早依赖低价年付作为主要增长方式。

标准版和顾问版也不宜先用大幅年付折扣换取成交。

# 十三、单人运营能够承受多大规模？

已确认的个人时间条件：

- 每天约6小时
- 每周约30小时
- 每月暂按22个工作日估计132小时

协会公益投入约每周2–4小时。

剩余时间需要同时承担：

- 销售与客户沟通
- 首次体检与建档
- 正式会员交付
- AI工作流完善
- 管理与财务
- 重要问题处理
- 协会合作之外的资源对接

因此不能直接把132小时全部用于会员服务。

例如：

稳定服务12家混合会员，按原假设需要42小时/月。

这还没有计算：

- 新体验企业
- 客户获取
- 系统开发
- 异常问题
- 项目交付
- 管理沟通

从总工时看，短期可能存在容量空间。

但能否保持B02约定的响应时效，还取决于一天之内的时间分布，而不只是月度总工时。

特别是顾问版工作时间1小时首次响应，需要相应通知和服务安排。

### 早期建议

首先把：

**8–12家正式会员作为服务模型测算场景。**

它不是已经确认的获客目标，也不是单人服务能力上限。

是否扩大到更多客户，应依据真实工时、服务质量和客户留存判断。

# 十四、商业模式需要验证的关键指标

## 14.1 收入指标

**月度经常性收入（MRR）**

统计当月有效正式会员按其实际合同价格折算的月度经常性收入。

不把一次性体验费与专项项目收入计入MRR。

对于年付合同，按服务月份进行合理折算，而不是将全年收款计作一个月的经常性收入。

**专项服务收入**

单独记录项目金额、交付周期和相关成本。

**收入结构**

区分：

- 会员收入
- 体验收入
- 专项收入
- 其他实际收入

## 14.2 获客与转化

- 有效需求接触数量
- 体验付费客户数量
- 体验完成率
- 正式会员转化率
- 各渠道的真实获客成本
- 协会转介与其他渠道的差异

## 14.3 会员留存

重点追踪：

- 首次转正
- 次月续费
- 第三个月仍在使用
- 第六个月是否续费
- 停止服务的主要原因

不能仅凭首批30天体验推断六个月留存。

## 14.4 服务使用与成本

- 首次建档实际工时
- 每月顾问人工工时
- 每家企业消息与问诊次数
- 主要材料交付数量
- AI辅助实际节省的时间
- 工具及专业外包成本
- 额外需求发生频率

## 14.5 客户获得的真实价值

- 已发现并核实的经营问题
- 已完成的行动
- 有效资源对接
- 被客户实际使用的分析与材料
- 可以证实的成本改善或经营变化
- 客户明确反馈的节省时间

不把未经验证的机会线索当作实际经营成果。

# 十六、商业模式的三个战略选择

## 选择一：是否继续维持99元完整30天体验？

目前应暂时保留已经确定的体验规则，用于首批真实验证。

但需要记录每家企业完整工时。

如果实际投入长期高于预期，而正式转化和留存不足，应考虑后续调整：

- 首次体检范围
- 体验内容
- 体验定价
- 会员首期收费方式
- 客户准入条件

这些调整需要另行修订产品和合同文件，不能在已签约客户服务期间单方缩减权益。

## 选择二：399元是否继续作为主要套餐？

当前仍以399元为重点测试产品。

但不应预先认定它是最终最优价格。

如果正式会员实际需要5小时以上人工，必须评估：

- 是否提高价格
- 是否缩小常规服务范围
- 是否改用更明确的工时或额度
- 是否优化行业工作流
- 是否让部分需求进入专项服务

## 选择三：长期更重视订阅还是专项？

暂不作排他选择。

建议：

**以会员服务验证经常性需求，以专项服务验证高价值需求，同时分别记录利润和交付成本。**

等真实数据出现后，再决定哪个是主要利润来源。

# 十七、不同验证结果下的商业决策

### 情景A：会员愿意续费，且月人工可控

进一步优化工作流，扩大有效客户来源。

订阅服务可能成为长期主营业务。

### 情景B：老板喜欢首次体检，却不愿持续使用

考虑独立经营诊断产品，不强行推销会员。

### 情景C：普通会员需求较轻，但不断出现高价值项目

可以提高专项服务业务比重，以会员关系维护和需求发现作为辅助。

但仍需验证专项业务是否具备持续性。

### 情景D：会员数量增加，人工工时同步快速增加

应先修订服务标准和产品边界，而不是直接招聘扩大规模。

### 情景E：协会合作积极，但缺少真实商业客户

继续把协会视为专业网络和市场研究渠道，同时通过其他途径验证直接购买需求。

不要把协会组织活跃度误判为商业成功。

# 十九、C02的最终结论

**第一，会员业务是建立持续客户关系的基础，但低价会员未必天然盈利。**

尤其是399元标准版，必须同时验证服务时间和续费周期。

**第二，99元体验主要是一种低成本购买门槛，而不是能够覆盖首次体检成本的收入产品。**

如果客户转正，99元全额抵扣意味着首次体验的人工投入需要从长期关系中回收。

**第三，专项经营分析和数字化服务可能带来更高单笔贡献，但不能在没有成交数据之前把它当作利润保证。**

**第四，协会可能降低信任和客户接触成本，但公益时间、商业客户和专业服务资源应分别核算。**

**第五，创业初期不需要证明自己能服务上千家企业。**

真正重要的是：

> **能不能找到几家愿意长期购买服务的企业，并以可控的人工投入持续为他们创造真实价值。**
