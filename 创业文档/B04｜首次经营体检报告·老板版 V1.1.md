# 报告说明

这不是财务审计，也不是法律、税务专业意见。

我们做的是：

> **帮你把经营情况看清楚一点，把真正重要的事情找出来，并持续跟进。**

有些事情如果需要律师、会计师、税务师或其他专业人员处理，我们会告诉你，并协助找到合适的人。

# 内部使用说明

> 以下内容不进入老板正式报告，可作为顾问工作底稿。

老板版报告正式发送前，顾问至少确认：

- [ ] 一句话可以说明企业现在最核心的情况
- [ ] 重点发现原则上不超过3项
- [ ] 每项发现都有事实或依据
- [ ] 推测没有写成确定事实
- [ ] 语言不使用不必要的专业术语
- [ ] 有数字时尽量翻译成老板容易理解的影响
- [ ] 行动事项具体到“谁、做什么、什么时候”
- [ ] 没有一次给老板大量建议
- [ ] 后续监测事项控制在真正重要的范围
- [ ] 数据不足的地方明确说“不知道”
- [ ] 老板能在3分钟内看完主要内容
- [ ] 顾问能在10分钟左右讲清核心结论

# 模板使用原则

首次体检老板版原则上：

**3–5页。**

特别复杂企业：

**原则上不超过8页。**

如果需要更详细的数据分析、图表、证据、计算过程和专业判断：

放入内部分析底稿或专项附件。

不要为了显示专业而把复杂内容全部塞进老板主报告。

最终标准只有三个：

> **看得懂。**

> **知道先做什么。**

> **愿意继续让我们帮他盯着。**
