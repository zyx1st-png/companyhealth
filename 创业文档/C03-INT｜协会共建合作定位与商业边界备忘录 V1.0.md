# C03-INT｜协会共建合作定位与商业边界备忘录 V1.0

**保密级别：内部使用，不随C03对外建议书发送**\
**适用对象：** 企业经营健康管理项目发起人\
**制定日期：** 2026年10月8日\
**决策状态：** 创业者内部合作原则，尚未与协会达成一致

---

## 一、已经确定的个人战略

### 1.1 选择双重角色

愿意：

- 深度参与协会企业经营服务体系的规划。
- 在条件合适时牵头经营管理相关专业板块。
- 协助建立企业需求识别、资源协同与服务跟进机制。
- 为协会提供有限的公益性专业支持。

同时坚持：

- 独立建设企业经营健康管理产品。
- 保留独立经营主体和品牌。
- 保留依法享有的原有知识产权和技术成果。
- 保留对独立业务的经营决策及定价权。
- 允许企业在自愿情况下直接购买服务。
- 不把协会作为唯一获客渠道。

**基本战略：在协会中建立专业影响力，在独立公司中建立可持续商业能力。**

### 1.2 当前不承诺的事情

不因口头邀请而立即承诺：

- 担任正式专委会负责人
- 负责整个协会的企业数据库
- 长期管理走访志愿团队
- 免费建设协会AI平台
- 为全部会员提供咨询
- 免费负责秘书处日常事务
- 无偿开放自己的全部工作流与技术成果
- 独家或排他性地为协会服务

上述事项可以讨论，但必须重新确定工作范围和合作条件。

## 二、公益投入的时间边界

### 已确认的个人时间条件

- 每天投入创业项目约6小时。
- 暂按每周5个工作日。
- 每周总工作时间约30小时。
- 协会试点期公益投入，内部暂按每周2–4小时规划。

建议首轮合作验证时间：

**约4周，总计预留8–16小时公益投入。**

工时范围包括：

- 协会会议
- 方案讨论
- 企业走访
- 需求整理
- 团队沟通
- 必要的资料准备及交通时间

不是只有面对面会议才计算投入。

### 时间使用优先级

**第一优先：** 自己的经营健康管理产品与商业验证。

**第二优先：** 已同意参与的协会共建事项。

**第三优先：** 没有明确结果导向的协会临时事务。

如果协会需求超过每周4小时，应明确属于短期特殊支持还是持续性工作。

对于持续性超额投入，必须重新讨论职责、项目资源和支持方式。

**每周2–4小时是内部资源预算，不必在第一次见面时作为对外硬性承诺。**

## 三、协会公益服务与收费业务的边界

### A类：可以考虑公益投入的事项

例如：

- 提供企业需求分类方法。
- 对走访表提出简化建议。
- 参加少量企业服务讨论。
- 帮助判断哪些问题应交给专业人员。
- 协助设计需求跟进的最小流程。
- 就共性经营管理问题作适当交流。
- 对试点结果提出改进建议。

这些工作应有可控范围。

### B类：原则上属于独立商业服务

例如：

- 为企业做完整首次经营体检。
- 分析具体经营数据。
- 提供持续经营健康管理。
- 按周期生成经营简报。
- 完成多份专业经营材料。
- 深入解决企业专项管理问题。
- 定制客户专属AI流程。
- 长期承担一对一经营顾问工作。

应由企业自愿选择，并与合适的服务主体明确约定范围、费用和责任。

### C类：应单独讨论项目费用的事项

例如：

- 协会数据库开发。
- 协会统一服务平台建设。
- 协会日常服务团队管理。
- 大规模会员需求整理。
- 长期负责企业走访统筹。
- 完整协会AI系统开发。
- 为数十家企业统一出具体检报告。
- 协会长期运营报表和信息化维护。

这些不能因为接受专业顾问或板块负责人身份，就自动成为免费义务。

## 四、知识产权与项目归属

### 4.1 原有成果

在参与协会合作前形成的：

- 企业经营健康管理商业方案
- 产品与会员体系
- 经营体检方法
- 行业指标及模板
- AI工作流
- 软件代码
- 专业服务流程
- 自有品牌与设计

依法属于本人或相应权利主体的部分，原则上继续由原权利主体持有。

没有明确书面协议，不主动转让或排他授权。

### 4.2 协会已有成果

协会已有的：

- 会员名录
- 走访记录
- 内部管理制度
- 组织流程
- 原有信息系统
- 其他团队创造的成果

不能因个人参与共建而自动取得其所有权或自由使用权。

### 4.3 合作形成的新成果

需要区分：

**公共服务方法：**

可以考虑给予协会约定范围内的使用许可。

**针对协会专门开发的内容：**

应根据是否付费、开发投入及事前约定确定权属和使用权。

**双方共同开发的软件：**

必须在开发前确认：

- 需求范围
- 费用承担
- 源代码归属
- 部署主体
- 维护责任
- 使用范围
- 终止合作后的处理

不得仅凭口头“大家一起做”判断成果归属。

### 4.4 演示与分享的原则

第一次可以展示：

- 服务理念
- 简明业务流程
- 报告样例
- AI应用场景
- 协会需求闭环示意

不必提供：

- 全部技术提示词
- 客户原始数据
- 项目源代码
- 完整商业成本模型
- 未经整理的内部行业知识库

保护商业成果不等于拒绝合作，而是先明确合作用途。

## 五、客户关系与数据权责

### 5.1 三种关系必须区别

**协会会员：**

加入协会或参与协会活动的企业。

**协会介绍的潜在服务客户：**

经企业同意，愿意进一步了解经营健康管理的企业。

**正式商业客户：**

已经与独立服务提供方签订合同的企业。

三者不能直接画等号。

### 5.2 客户签约

独立商业服务原则上由客户与实际服务主体签约。

协会是否承担宣传、推荐、共同活动等职责，按合作安排确定。

不得向企业暗示购买商业服务是加入协会、获取资源或享受公共服务的条件。

### 5.3 数据的基本权责

协会会员资料和走访记录，由依法或依约负有管理责任的主体管理。

个人独立服务中获得的企业经营资料，在服务授权范围内处理。

双方交换个人信息、商业秘密或敏感经营资料，必须满足适用的授权和其他合法性要求。

### 5.4 不应接受的要求

- 要求协会把所有会员名单交给个人用于商业营销。
- 要求个人把全部付费客户的经营资料交给协会。
- 要求将双方资料默认接入同一个AI知识库。
- 要求把企业数据用于未经授权的其他商业目的。
- 未经允许将真实客户案例公开展示。

### 5.5 可以探讨的协同方式

经企业同意，可以反馈：

- 需求类别
- 是否完成对接
- 服务状态
- 是否仍需其他支持

机构层面的统计可以优先使用适当汇总或去标识化的信息，但是否构成匿名化以及能否分享，仍须结合具体内容判断。

## 六、组织角色的接受条件

李文雪电话中提出进入专业服务体系，并可能承担相应板块负责人职责。

在接受前，应进一步明确：

| 问题   | 需要确认               |
| ---- | ------------------ |
| 正式名称 | 智库专家、专委负责人、顾问或其他身份 |
| 组织权限 | 可以协调什么、决定什么        |
| 汇报关系 | 向谁汇报，与秘书处如何配合      |
| 工作范围 | 咨询指导、协调、执行还是团队管理   |
| 人员支持 | 是否有联系人、志愿人员或工作人员   |
| 时间要求 | 定期会议、走访及日常事务量      |
| 商业兼容 | 是否允许独立企业服务及收费      |
| 利益冲突 | 如何回避涉及本人公司的采购或推荐决策 |
| 对外宣传 | 如何使用协会名称、职务及标识     |
| 退出机制 | 不再承担职责时如何完成交接      |

如果组织尚未正式成立相关岗位，不能直接对外宣称已被任命。

### 判断原则

如果主要是专业方向建设和服务机制设计，可以考虑接受。

如果需要大量行政事务、人员管理或平台维护，则应重新确定时间、预算和资源。

## 七、商业收益与合作机制

### 7.1 现阶段的主要收入来源

以独立企业经营健康管理服务为主。

包含：

- 99元30天体验服务
- 199元基础会员
- 399元标准会员
- 1299元起顾问服务
- 独立报价的专项服务

上述价格属于当前创业验证方案，不应默认成为协会统一收费标准。

### 7.2 协会目前不视为确定的付费客户

虽然协会可能带来较多企业关系，但尚未确认：

- 机构采购预算
- 采购权限
- 合同条件
- 介绍客户数量
- 客户成交率
- 服务团队投入

因此不将协会未来采购或会员转化作为已经确定的收入。

### 7.3 渠道合作收益

未来如需考虑合理的推广费用、资源协作或服务合作收益，应先明确具体服务和对价。

如果本人获得协会职务，涉及本人公司承接协会业务，需要根据协会内部规则和适用要求披露利益关系、按程序审批并在必要时回避。

不使用不透明的个人介绍费或与协会职务挂钩的暗中利益安排。

### 7.4 不接受排他性绑定作为默认条件

协会可以推荐多个合适的企业服务机构。

个人公司也应可以通过其他渠道获得客户。

除非双方以后基于明确对价和商业条件另行达成合法协议，否则不建议接受长期排他安排。

## 八、首轮合作验证的内部投入控制

对外建议书提出2–3家企业和约30天验证周期。

内部应进一步限定：

**协会共建部分只验证需求闭环，不承担2–3家完整的30天经营健康管理交付。**

否则，每周2–4小时的公益投入很容易被耗尽。

建议内部任务分配：

| 工作内容      |    首轮投入上限建议 |
| --------- | ----------: |
| 与创始人及团队沟通 |       2–3小时 |
| 需求分类与流程设计 |       2–4小时 |
| 参与少量企业交流  |       3–5小时 |
| 试点反馈及方案修订 |       1–4小时 |
| **总体**    | **约8–16小时** |

具体时间以实际记录为准。

### 独立商业体验

如有企业希望进行完整30天经营健康管理，应使用独立服务协议。

99元为30天体验服务费，完成约定服务后不因不转正而退款，购买正式会员时全额抵扣；不自动续费，并保留依法应适用的其他处理规则。

在具备合法收费和交付条件之前，不提前开展批量商业收费。

这部分不计入协会公益工时。

## 九、下一次见面应争取的成果

### 最低可接受成果

- 协会了解了项目核心定位。
- 知道项目以独立企业经营为基础。
- 认可可以继续讨论专业服务协作。
- 明确现有走访及AI团队的基本分工。

即使没有马上介绍客户，也可以视为一次有效沟通。

### 理想成果

- 认可“企业需求闭环”的共建方向。
- 原则上允许独立商业服务与公益服务并存。
- 明确一个主要沟通联系人。
- 同意讨论2–3家企业的小规模验证。
- 约定下一次与核心团队交流的内容。

### 不应强求的成果

- 当场决定负责人岗位。
- 协会指定独家合作服务商。
- 承诺大量付费客户。
- 确定完整平台开发。
- 明确商业分成比例。
- 立即签署长期合作协议。

## 十、遇到不同合作要求时的建议回应

### 情况一：对方希望你直接负责整个企业服务板块

可以表达：

“经营管理服务这个方向我愿意参与设计，也愿意先牵头做一部分试点。不过长期负责哪些工作，可能需要把职责、配合人员和投入时间明确下来，这样以后才能持续做。”

### 情况二：对方希望你直接开发协会数据库

可以表达：

“数据库可以作为后面的方向。但我建议先把企业走访要收集什么、后续服务怎么跟进梳理清楚。否则平台做出来以后，可能还需要重新调整。真正的软件开发可以再单独确认需求和投入。”

### 情况三：对方认为协会服务应该全部免费

可以表达：

“协会基础性的会员服务，我认为可以有公益部分。我也愿意承担一定的专业支持。但涉及具体企业长期经营分析和持续顾问服务，投入会比较大，可能还是需要形成独立、可持续的服务机制。”

### 情况四：对方希望由协会统一掌握所有客户

可以表达：

“协会会员管理肯定还是协会负责。真正需要深入经营分析的企业，可以在同意以后由专业服务方单独服务。协会可以了解需求处理进度，但企业的详细经营资料还是要按授权管理。”

### 情况五：对方要求项目纳入协会统一管理

可以先问：

“这里说的纳入统一管理，主要是专业服务板块的工作协调，还是包括项目品牌、系统和商业经营？我觉得这几部分可以分开讨论。”

不要在没有明确含义时口头同意。

## 十一、需要警惕的合作风险

### 风险一：身份很好听，但没有明确职责

有职位、没有资源，最终变成大量义务劳动。

### 风险二：项目被逐渐视为协会内部资产

因为长期使用协会名义开展活动，外界逐渐无法区分独立业务与协会公共服务。

### 风险三：个人经营时间被行政事务挤占

特别是企业走访、会议、活动和会员管理，可能消耗大量时间。

### 风险四：专业团队交叉导致冲突

AI、信息化、财税、法务等专业方向之间，可能出现职责或商业机会分配问题。

### 风险五：把协会会员数量误判为商业客户规模

会员不等于活跃企业，也不等于具有经营咨询需求，更不等于愿意付费。

### 风险六：成果归属与数据处理不清楚

后续可能围绕平台、客户档案、行业模板和专业成果产生争议。

### 风险七：公益与收费混在一起

会员不知道哪些是协会基础服务，哪些是独立商业服务，导致信任或利益冲突。

## 十二、必须明确的原则与可以协商的事项

### 原则上应坚持

- 独立商业主体及品牌。
- 既有知识产权和技术成果不自动转让。
- 正式商业服务由企业自愿购买。
- 协会会员数据与商业客户资料按各自权限管理。
- 不接受无边界的免费长期服务。
- 不在没有明确约定时承担大型系统开发。
- 涉及本人商业利益的组织决策保持透明。
- 不对未经正式确认的组织身份进行公开宣传。

### 可以灵活协商

- 专业板块的正式名称。
- 是否担任某个专业负责人。
- 参与走访的具体次数。
- 公益服务的活动形式。
- 联合宣传方式。
- 行业讲座和培训安排。
- 资源推荐流程。
- 未来专项项目的合作形式。
- 双方共同投入的新系统如何授权使用。

### 需要后续协议明确

- 长期职责和时间投入。
- 新开发成果的权属。
- 联合项目的收费和成本。
- 客户合同及服务责任。
- 收费服务的推荐规则。
- 保密、数据处理与退出机制。

## 十三、建议设置的合作推进门槛

### 第一阶段：方向沟通

目标：

了解协会需求、人员分工和双方合作态度。

不承诺长期职务。

### 第二阶段：小范围验证

目标：

验证企业需求识别、分类、服务转介和结果反馈。

首轮约30天。

### 第三阶段：合作条件确认

如果试点有价值，再讨论：

- 是否设立正式专业服务板块
- 是否由本人负责
- 长期工作投入
- 协会提供的资源
- 商业服务边界
- 技术成果与数据规则

### 第四阶段：长期合作

只有在双方达成明确条件后，才扩大长期责任、团队和平台投入。

## 十四、内部最终决策标准

未来是否深度参与协会经营服务建设，不只看组织头衔和潜在企业数量。

重点判断四个问题：

**第一，是否存在真正的企业经营需求？**

**第二，协会合作是否能提升这些需求被发现和解决的效率？**

**第三，参与协会会不会损害独立项目的商业发展与时间投入？**

**第四，双方是否愿意建立明确、可持续的权责与收益机制？**

如果前三项具备积极信号，第四项又可以达成合理安排，那么值得深入推进。

如果协会主要要求持续免费运营，而独立项目和商业服务空间长期无法明确，则应降低参与程度。

---

## 十五、个人战略底线

> 我参与协会，不只是为了获得一个职务。

> 我建设经营健康管理，也不只是为了从协会获得客户。

> 最有价值的合作，是把协会的组织资源、会员服务需求和我的专业服务能力结合起来，让企业真正获得帮助，同时建立可持续的商业模式。

**可以共建服务体系，但不在边界不清时让渡独立项目。**

**可以投入公益时间，但不将无限期无偿服务作为合作基础。**

**可以参与组织建设，但长期职责必须与资源和能力相匹配。**
