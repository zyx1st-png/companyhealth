# B04-1｜行业经营体检模板体系与指标库 V1.0

**适用项目：** 企业经营健康管理\
**文档性质：** 产品设计与开发规范\
**对应文件：** B03-1 信息采集规范、B03 首次体检方法、B04 老板版报告模板

---

## 一、产品定位

本体系用于解决三个问题：

1. 不同行业应该检查哪些经营问题？
2. 哪些经营指标能够真正反映企业状况？
3. 如何根据企业的数据条件和需求，生成适合的体检报告？

不为所有企业使用同一份通用报告，也不为每个行业重新开发整套系统。

采用以下架构：

**通用经营体检底座 + 行业指标与分析模块 + 企业个性化诊断 + 分层报告输出**

核心原则：

> **通用方法保证质量，行业分析体现专业，个性化诊断创造价值。**

行业专业化不意味着大量堆砌术语，而是能够提出真正符合这个行业经营逻辑的问题，并通过数据、事实和经验形成可执行建议。

---

## 二、统一体检底座

无论哪个行业，必须保留六项核心内容。

| 通用模块   | 要回答的问题           | 主要产出       |
| ------ | ---------------- | ---------- |
| 企业经营模型 | 企业怎么赚钱？          | 经营模型简图     |
| 当前经营状态 | 生意现在怎么样？         | 一句话结论与重要变化 |
| 问题与风险  | 哪里已经出问题，哪里可能出问题？ | 重点发现       |
| 经营机会   | 有什么值得改善或利用的机会？   | 机会判断       |
| 行动建议   | 接下来应该先做什么？       | 30天行动计划    |
| 持续经营监测 | 以后需要长期盯什么？       | 企业专属监测清单   |

后台继续保留B03定义的八个观察维度、证据卡、信息来源、数据缺口和优先级判断机制。

客户报告不必全部展示这些过程。

---

## 三、首次报告的三种深度

报告深度由行业复杂程度、企业数据条件、老板关注的问题以及服务范围共同决定。

### A类｜经营体检简明版

**参考篇幅：1–3页**

适合：

- 小微经营主体
- 数据比较少的企业
- 首次仅希望了解主要问题的企业
- 需要通过微信快速查看的老板

重点展示：

- 一句话经营结论
- 1–3项重要发现
- 当前值得抓住的机会
- 未来30天的主要行动
- 后续需要持续关注的事项

### B类｜行业经营体检专业版

**参考篇幅：4–6页**

适合：

- 已有一定经营规模
- 有基础财务或业务数据
- 经营结构比较清晰
- 希望看到有依据的专业分析的企业

在简明版基础上增加：

- 行业核心指标
- 2–4张真正有价值的图表
- 具体业务结构分析
- 针对性的改善机会
- 必要的同行或历史对照

### C类｜专项深化版

**篇幅由范围决定，原则上控制主报告，详细内容作为附件。**

适合：

- 准备扩张、开店或投资
- 营收下滑、现金紧张等重大问题
- 多门店或多业务经营
- 需要专门做经营决策分析的企业

进一步增加：

- 专项利润测算
- 情景模拟
- 投资回收分析
- 项目或门店对比
- 改善方案及实施路径

C类不是默认会员权益，具体工作范围按照套餐约定或专项服务另行确认。

**重要：不能因为客户购买高档服务，就在数据不足时生成复杂但不可靠的分析。**

# 四、首批六类行业模板

## 4.1 餐饮与茶饮

### 核心经营逻辑

**让足够多的顾客进店或下单，在控制食材、人工、场地及平台费用后保持盈利。**

### 老板最关心的问题

- 最近为什么生意变少？
- 美团和抖音做活动到底赚不赚钱？
- 哪些菜品最值得卖？
- 人工、食材是不是越来越贵？
- 哪些时间段生意不好？
- 再开一家店值不值得？

### 首次建议收集

最小信息：

- 最近3个月营业额
- 主要销售渠道
- 堂食和线上收入
- 主要菜品与套餐
- 员工数量及人工成本
- 食材成本的可得记录
- 租金及其他主要固定费用

可追加：

- 每日订单
- 客流与客单价
- 美团、抖音订单
- 平台佣金与活动补贴
- 外卖履约费用
- 菜品成本
- 评价与复购记录

### 行业指标库

| 指标      | 经营意义        | 计算或判断方法                |
| ------- | ----------- | ---------------------- |
| 日均营业额   | 生意规模及变化     | 期间净营业额÷营业天数            |
| 客单价     | 顾客每次消费多少    | 实收销售额÷有效订单数            |
| 食材成本率   | 卖货成本是否过高    | 对应期间食材耗用成本÷相关收入        |
| 人工成本率   | 员工投入是否合理    | 人工成本÷相关营业收入            |
| 堂食/线上占比 | 收入依赖哪些渠道    | 各渠道收入÷总收入              |
| 平台订单贡献  | 线上订单是否有价值   | 实收收入减去相关食材、平台和履约等可归属费用 |
| 菜品贡献    | 哪些产品更值得推广   | 菜品收入减对应直接变动成本          |
| 盈亏平衡营业额 | 每月卖多少才能覆盖成本 | 固定成本÷贡献毛利率，需口径完整       |

实际计算时，退款、折扣、平台补贴、税费和成本归属必须统一口径。

### 专业版重点图表

1. 最近3–6个月营业额趋势
2. 堂食、美团、抖音收入与贡献对比
3. 主要菜品的销量与贡献
4. 收入、成本和费用结构

### 典型经营发现

例如：

**某平台订单量增长，但扣除促销补贴、平台费及履约成本后，每单剩余收益偏低。**

这比笼统建议“增加线上推广”更具有专业价值。

### 后续经营监测

日/周营业额、主要平台订单、重要差评、食材成本、活动效果、门店重要待办。

## 4.2 商贸、批发与经销

### 核心经营逻辑

**采购商品 → 找客户销售 → 形成毛利 → 及时收款 → 资金再次投入采购。**

这一类企业的主要风险往往与客户、库存和资金周转同时相关。

### 老板最关心的问题

- 销售额不少，为什么手上没钱？
- 哪些客户真正赚钱？
- 哪些客户欠款太久？
- 库存是不是压多了？
- 哪些产品值得继续代理？
- 要不要扩大赊销或增加经销区域？

### 首次建议收集

最小信息：

- 最近3–6个月销售额
- 主要产品类别
- 主要客户
- 应收账款概况
- 当前库存
- 主要采购成本及费用

可追加：

- 客户销售明细
- 采购及销售价格
- 应收账龄
- 库龄
- 供应商账期
- 退货及返利政策
- 仓储物流费用

### 行业指标库

| 指标      | 经营意义      | 计算或判断方法             |
| ------- | --------- | ------------------- |
| 销售毛利率   | 卖货剩余多少毛利  | 销售收入减对应商品成本，再除以销售收入 |
| 客户收入贡献  | 收入依赖谁     | 单客户收入÷总收入           |
| 前五大客户占比 | 客户集中度     | 前五客户收入÷总收入          |
| 应收账龄    | 哪些钱拖得久    | 按合同到期日或开票日分层，需注明口径  |
| 逾期应收占比  | 回款压力      | 已逾期应收÷总应收           |
| 库存周转天数  | 货品周转速度    | 平均存货÷期间销售成本×期间天数    |
| 滞销库存占比  | 有多少货长期不动  | 按约定库龄口径计算           |
| 产品贡献    | 哪些商品真正赚钱  | 产品收入减对应成本及可归属费用     |
| 回款达成率   | 应收是否按计划收回 | 实际按期回款÷计划到期应回款      |

### 专业版重点图表

1. 应收账龄分布
2. 前十大客户收入变化
3. 商品毛利与销售规模对照
4. 库存库龄分布

### 典型经营发现

例如：

**营业额持续增长，但应收账款增长更快，资金可能越来越多地被客户占用。**

下一步应该分析客户账期、实际回款、逾期客户和采购付款节奏，而不只是继续增加销售。

### 后续经营监测

重点客户采购变化、逾期应收、库存积压、供应商价格、招投标、客户和渠道机会。

## 4.3 零售与连锁门店

### 核心经营逻辑

**通过商品、选址、客流、成交与复购创造收入，通过门店效率和商品结构获得利润。**

### 老板最关心的问题

- 哪一家店比较赚钱？
- 哪些店只是营业额高，利润却低？
- 顾客为什么不来了？
- 哪些商品卖不动？
- 要不要再开店？
- 会员做了很多，但有没有实际作用？

### 首次建议收集

最小信息：

- 各门店营业额
- 门店数量和位置
- 主要商品结构
- 员工与租金
- 有效订单量
- 当前库存

可追加：

- 每日客流
- 销售小票
- 会员消费记录
- 商品成本
- 门店面积
- 损耗
- 营销费用

### 行业指标库

| 指标      | 经营意义                   |
| ------- | ---------------------- |
| 同店销售增长  | 排除新增门店影响，看老店有没有增长      |
| 店均营业额   | 对比门店经营规模               |
| 坪效      | 一定时间内单位经营面积产生多少销售      |
| 人效      | 一定时间内员工产生多少销售或贡献       |
| 客单价     | 顾客单次消费水平               |
| 商品售罄与滞销 | 商品结构和补货效率              |
| 会员复购率   | 有多少老客户持续回来             |
| 门店贡献利润  | 单店收入扣除可归属商品成本及经营费用后的贡献 |

注意：同店增长必须使用真正可比的门店及时间范围，不能直接用总销售额替代。

### 专业版重点图表

1. 门店经营表现排名
2. 销量高、利润高、库存高商品矩阵
3. 新老门店销售对比
4. 会员复购变化

### 后续经营监测

门店销售、重点商品、库存、会员变化、门店租约、商圈竞争及新店机会。

## 4.4 工程、装修与项目型企业

### 核心经营逻辑

**取得项目 → 签订合同 → 组织施工或交付 → 控制项目成本 → 验收结算 → 收回款项。**

这类企业不能简单套用零售行业的销售、库存和复购模板。

### 老板最关心的问题

- 手上项目不少，为什么缺钱？
- 哪些项目最后没有赚到钱？
- 哪些项目快超预算？
- 工期延期会有什么影响？
- 哪些款项迟迟结算不了？
- 新项目能不能接？

### 首次建议收集

最小信息：

- 在手项目清单
- 合同金额
- 当前施工或交付进度
- 已收款与未收款
- 已发生主要成本
- 项目负责人
- 预计完工时间

可追加：

- 项目预算
- 成本明细
- 变更签证
- 结算资料
- 分包付款
- 工期记录
- 合同关键付款节点

### 行业指标库

| 指标       | 经营意义            |
| -------- | --------------- |
| 在手合同额    | 当前项目储备          |
| 项目预计毛利   | 项目最终可能赚多少       |
| 成本预算偏差   | 实际成本是否超过计划      |
| 工程或交付进度  | 项目完成情况          |
| 合同付款达成   | 应收款是否按节点到账      |
| 已完工未结算金额 | 完成工作但未完成结算的资金压力 |
| 项目现金缺口   | 未来一段时间收支能否覆盖    |
| 工期偏差     | 是否存在延期风险        |

项目利润预测必须区分已发生成本、预计剩余成本、已确认变更和尚未确认的索赔。

### 专业版重点图表

1. 各项目预计利润与预算偏差
2. 合同、进度、回款对比
3. 未来数月资金收支预测
4. 项目延期与风险分布

### 典型经营发现

例如：

**项目施工进度达到较高水平，但回款明显落后于合同约定节点。**

此时优先事项可能不是继续接新项目，而是推进结算、回款和资金安排。

### 后续经营监测

合同节点、项目进度、应收回款、预算超支、招投标机会、关键证照及安全合规提醒。

## 4.5 生产制造与加工

### 核心经营逻辑

**获得订单 → 采购原料 → 安排生产 → 控制成本和损耗 → 按期交付 → 收款。**

### 老板最关心的问题

- 订单明明不少，为什么利润不高？
- 哪种产品越做越不赚钱？
- 设备是不是没有充分利用？
- 原材料涨价要不要调整报价？
- 哪些订单值得接？
- 哪些环节最容易产生损耗？

### 首次建议收集

最小信息：

- 主要产品
- 近期订单
- 销售价格
- 主要原材料成本
- 人工与主要制造费用
- 生产能力
- 库存和交付情况

可追加：

- 工单
- 标准成本
- 实际领料
- 工时
- 设备运行记录
- 废品与返工
- 生产排程
- 交货准时率

### 行业指标库

| 指标      | 经营意义         |
| ------- | ------------ |
| 产品单位贡献  | 每件产品能够贡献多少收益 |
| 材料成本占比  | 原材料压力        |
| 生产损耗率   | 材料或产出损失      |
| 返工率     | 质量与效率问题      |
| 设备产能利用率 | 生产能力是否闲置或过载  |
| 按期交付率   | 订单履约能力       |
| 库存周转    | 原材料及成品资金占用   |
| 订单预计毛利  | 哪些订单值得接受     |

需根据工艺确定损耗基准，不能跨不同工厂、产品直接套用统一阈值。

### 专业版重点图表

1. 产品订单贡献排名
2. 原材料成本变化
3. 产能利用与交货情况
4. 损耗及返工分布

### 后续经营监测

订单、交期、原材料价格、库存、损耗、核心客户、设备维护和可申请的技改项目。

## 4.6 专业服务与生活服务

适用于咨询、设计、培训、美业、家政及其他服务型企业。

不同细分行业仍应进一步区分。

### 核心经营逻辑

**获得客户 → 转化成交 → 提供服务 → 收款 → 形成复购或转介绍。**

### 老板最关心的问题

- 客户从哪里来？
- 哪种推广方式有效？
- 为什么来了咨询却不成交？
- 为什么老客户不再来？
- 员工有没有真正创造收益？
- 预约多了，为什么利润没有上去？

### 首次建议收集

最小信息：

- 最近3个月营业额
- 客户来源
- 主要服务项目
- 成交订单
- 人员数量
- 服务价格
- 主要成本

可追加：

- 咨询记录
- 预约数据
- 成交记录
- 复购数据
- 员工工时
- 推广费用
- 退款
- 预收款及未履约服务

### 行业指标库

| 指标        | 经营意义             |
| --------- | ---------------- |
| 咨询成交率     | 咨询客户有多少最终付费      |
| 客户获取成本    | 获得一名新客投入多少推广成本   |
| 客单价       | 每笔消费金额           |
| 老客复购率     | 客户能否持续回来         |
| 员工有效服务利用率 | 工作时间有多少实际用于可收费服务 |
| 单项服务贡献    | 哪些服务更有经营价值       |
| 预约取消率     | 服务产能损失           |
| 预收未履约金额   | 已收款但尚需提供的服务义务    |

涉及医疗、法律等有特殊资质要求的行业时，必须另行设置专业边界，不直接套用一般生活服务指标。

### 专业版重点图表

1. 客户来源与成交对比
2. 新老客户贡献
3. 服务项目收益
4. 员工服务利用率

### 后续经营监测

新增客户、成交、复购、预约、客户评价、人员排班和相关经营机会。

# 五、建立真正可复用的行业指标库

不能只把指标名称写进提示词。

每一个可计算指标，都应具备明确的定义。

## 5.1 指标标准字段

| 字段   | 说明                |
| ---- | ----------------- |
| 指标ID | 系统中的唯一标识          |
| 行业分类 | 适用的行业或子行业         |
| 指标名称 | 例如应收账款逾期率         |
| 通俗名称 | 例如到期还没收到的钱占多少     |
| 经营意义 | 为什么要看             |
| 计算公式 | 明确分子、分母和口径        |
| 所需数据 | 数据字段及时间范围         |
| 来源   | Excel、平台、收银、财务软件等 |
| 更新频率 | 日、周、月等            |
| 判断条件 | 什么情况需要关注          |
| 适用限制 | 什么情况下不能算或不能比较     |
| 数据质量 | 是否完整、是否可核实        |
| 输出方式 | 客户报告、内部底稿、经营提醒    |
| 处理成本 | 获取及维护该指标的大致人工成本   |

## 5.2 示例：应收账款逾期率

**指标名称：** 应收账款逾期率

**老板看得懂的名称：** 到期还没收到的钱占多少

**公式：**

到期未收应收余额 ÷ 同口径应收余额 × 100%

**需要数据：**

- 客户
- 应收金额
- 应收到期日
- 实际回款
- 当前未收余额

**适用行业：**

商贸、制造、工程、B端服务等。

**提醒规则：**

优先根据企业过去的逾期水平、合同账期和资金承受能力确定，而不是强制所有企业使用同一个百分比。

**客户展示：**

> 最近到期该收的钱，有一部分还没到账。建议先联系金额最大、逾期时间最长的几家客户。

**使用限制：**

如果没有合同账期，只能按开票日或其他约定口径做账龄分析，不能直接认定已经逾期。

# 六、行业模板如何自动选择

系统不应仅通过营业执照行业分类确定模板。

因为同一家公司可能同时从事零售、批发和线上电商，也可能同时经营餐饮和住宿。

模板选择按照以下流程：

### 第一步：确定主要赚钱方式

重点判断：

- 是直接面对消费者，还是企业客户？
- 卖商品、做服务，还是交付项目？
- 主要收入来自门店、平台、经销还是合同？
- 收入发生后，多久才能收到款？

### 第二步：选择主行业模板

以当前最主要的经营方式为依据。

### 第三步：识别兼营业务

例如：

**餐饮 + 线上团购**：以餐饮为主，增加平台渠道分析。

**商贸 + 自有零售门店**：以商贸为主，增加门店模块。

**制造 + 经销**：以制造为主，增加客户、渠道及应收模块。

**工程 + 设备销售**：采用项目与商贸混合模块。

### 第四步：确定老板最关心的问题

例如同一家商贸企业：

- 关注现金 → 重点做应收和库存。
- 关注增长 → 重点做客户和渠道。
- 准备扩张 → 重点做业务复制及资金需求。

### 第五步：检查数据条件

数据充足：进行实际计算和对比。

数据有限：进行初步判断并列明需要核实的资料。

只有访谈：以经营理解和待验证问题为主，不制作虚假精确图表。

### 第六步：确定交付深度

结合企业需求和服务范围，输出简明、行业专业或专项深化版本。

# 七、行业判断不能使用统一标准

这点必须作为系统规则。

例如：

某餐饮店食材成本率35%，不能仅因为高于网上某个数字就断定异常。

可能存在：

- 火锅与快餐差异
- 套餐促销
- 堂食与外卖差异
- 定价策略不同
- 食材品质不同
- 数据是否含损耗不同

因此判断顺序应优先采用：

**企业自身历史 → 同企业门店对比 → 业务结构解释 → 经过核实的可比行业数据。**

没有可靠同行数据时，不写“高于行业平均水平”。

不能用上市企业的大型连锁经营指标直接判定地方小店经营水平。

# 八、行业专业图表标准

图表不能为了视觉丰富而存在。

每张图必须对应一个真实问题。

| 图表类型   | 应回答的问题      |
| ------ | ----------- |
| 销售趋势   | 生意是变好还是变差？  |
| 收入结构   | 钱主要从哪里来？    |
| 毛利贡献   | 哪些业务真正创造毛利？ |
| 应收账龄   | 钱压在哪些客户那里？  |
| 库存库龄   | 哪些货压得最久？    |
| 门店对比   | 哪一家表现最好或最差？ |
| 项目资金预测 | 未来哪些时间可能缺钱？ |
| 客户复购趋势 | 老客户是否还在购买？  |
| 成本拆解   | 钱主要花在哪里？    |

原则上，首次行业专业版只选择2–4张最重要的图。

对于只有访谈数据的客户，不强制生成量化图表。

# 九、老板版报告的统一结构

无论行业，建议统一保留五部分：

## 01｜先看结论

一句话经营判断。

一个正向信号。

一个主要问题或风险。

一个值得关注的机会（有依据时）。

## 02｜行业经营情况

选择本行业最重要的3–5项经营指标。

展示1–2张关键图表或事实说明。

## 03｜发现了什么

1–3项最重要的发现。

每项包括：

**发生了什么 → 为什么值得关注 → 建议怎么办。**

## 04｜未来30天

原则上最多3项核心行动。

明确负责人与时间，未确认的事项标为建议而不是已承诺。

## 05｜以后持续关注什么

根据本行业特点和数据来源确定监测事项。

明确：

- 监测指标
- 数据如何获得
- 预计多久更新
- 发现哪些变化会提醒

对暂时没有数据来源的事项标记为待建立，不假装已经实现自动监测。

# 十、与套餐体系的关系

行业模板决定分析方向。

套餐决定服务范围。

两者不能混为一谈。

| 服务档位        | 首次体检建议重点            | 后续服务             |
| ----------- | ------------------- | ---------------- |
| 基础版199元/月   | 简明体检 + 必要的行业问题识别    | 基础信息与事项关注        |
| 标准版399元/月   | 简明结论 + 有数据支持的行业重点分析 | 周报、月度经营简析及日常问诊   |
| 顾问版1299元/月起 | 更充分的经营分析与顾问解读       | 月度深度复盘与约定范围的专项分析 |

以上为行业模板与现有套餐的建议适配方式。正式承诺以B01、B02及客户协议为准。

同一个行业不强制采用同样的分析深度。

基础版不能因为采用专业行业模板就自动包含复杂专项分析。

首次体检的较高建档和分析成本，应在试运营中单独记录，评估如何通过续费、客户生命周期价值和服务效率覆盖。

# 十一、AI与顾问的工作流程

### AI负责

- 整理企业基本信息
- 判断可能适用的行业模块
- 建议定向资料清单
- 识别可计算指标
- 辅助生成指标计算任务
- 提出异常线索
- 整理外部行业信息
- 生成证据卡初稿
- 生成行业报告初稿
- 将专业术语转换成老板能够理解的表达

### 程序负责

- 关键经营数字计算
- 指标口径检查
- 数据去重及必要清洗
- 趋势和结构分析
- 图表数据生成

### 顾问负责

- 确认企业真正的经营模式
- 判断是否选错行业模板
- 审核异常与关键数字
- 判断行业背景是否适用
- 确定重要发现
- 判断哪些建议切实可行
- 确认本次服务范围
- 与老板校准结果
- 对正式交付负责

# 十二、行业体检的质量红线

以下情况不得通过增加报告页数掩盖：

1. 没有数据，却生成精确经营指标。
2. 使用未经核实的所谓行业平均值。
3. 只列出指标，没有解释经营意义。
4. 把同行差异直接认定为经营问题。
5. 把预测改善收益写成已实现收益。
6. 把潜在政策、补贴或订单写成确定机会。
7. 不区分收入、毛利、贡献利润和最终净利润。
8. 忽略企业的季节性、区域、规模和业务差异。
9. 没有可执行的行动建议。
10. 为了显示专业而使用大量不必要的术语。
11. 未经授权扩大企业数据使用范围。
12. 未核实数据更新能力，就承诺实时或持续自动监测。

真正的行业专业性，应该体现在准确提出问题、正确处理数据和形成具体建议，而不是图表数量。

# 十三、首批开发优先级

不建议第一阶段同时开发六个完整行业包。

建议按照可获得数据、常见经营问题和实际客户需求逐步开发。

## P0｜通用体检底座

先完成：

- 企业行业与经营模式识别
- 通用采集字段
- 证据及数据来源管理
- 指标定义与计算规则
- 重点发现生成
- 30天行动计划
- 老板版报告生成
- 经营监测清单生成

## P1｜餐饮与商贸批发

优先成熟化：

**餐饮模板**

- 平台销售分析
- 菜品贡献
- 单店收支
- 客流与客单
- 经营异常

**商贸批发模板**

- 客户销售
- 应收账龄
- 库存周转
- 商品贡献
- 资金占用

选择这两类作为首批，并不意味着其他行业不能服务。其他行业可以先用通用底座加人工定向模块。

## P2｜零售与工程项目

增加：

- 多门店对比
- 商品与会员分析
- 项目收支
- 合同节点
- 回款及项目风险

## P3｜制造与专业服务

增加：

- 订单成本
- 生产损耗
- 产能效率
- 客户转化
- 复购
- 服务人员效率

每一个新行业模块应通过真实企业数据和顾问复核验证后，再作为标准化能力推广。

# 十四、MVP验收标准

第一阶段不追求“支持所有行业”。

建议使用至少两种不同经营模型的试点企业，验证以下事项：

- 能识别主要行业及兼营业务。
- 能生成符合该行业的定向资料清单。
- 能区分可计算、待补充及不可计算的指标。
- 所有正式展示的关键数字可追溯。
- 能发现至少一个有实际意义的经营变化，或如实说明暂未发现。
- 老板版结论与内部分析底稿一致。
- 能生成明确的行动计划。
- 能提出具备实际数据来源的持续监测事项。
- 顾问可以编辑、否决或替换AI判断。
- 能记录本次实际人工工时、客户理解情况及报告使用反馈。

没有发现问题的企业，也可以通过上述验收，不强制创造异常。

**B03-1《首次经营体检信息采集规范》**

**B04《首次经营体检报告·老板版》**

**B02《服务清单与服务标准》**

同步更新首次体检交付口径，取消旧的总健康评分表述，并明确行业专业分析不等于无限专项咨询。

**MVP开发需求**

应把行业模板、指标定义、证据链、报告生成和监测配置设计为独立可维护模块，避免把所有规则写死在单个提示词中。

# 十六、最终产品原则

**不是每家企业都要看同样的内容。**

**不是每个行业都要做同样深度的分析。**

**不是图表越多，服务越专业。**

**真正的专业，是知道这个行业应该看什么、为什么看、看到问题后怎么处理。**

最终目标是让老板感受到：

> **你们不仅懂经营管理，还真正懂我这个行业，而且能长期帮我把重要的事情盯住。**
