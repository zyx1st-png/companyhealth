# 企业经营健康管理服务清单与服务标准

Oct 6, 2026 · @zhangyuxin

适用于资讯版（199 元/月）、标准版（399 元/月）、顾问版（1299 元/月起）三档会员及增值服务。

## 一、服务总则

每家会员企业配一名专属顾问，通过企业微信长期服务；AI 负责信息收集、整理和初稿，所有发给企业的内容都由顾问审核后发出。

**服务时间与响应时效**

服务时间为工作日 9:00–18:00，非工作时间收到的消息在下一个工作日处理。“响应”指顾问首次回复并确认需求，完成时限按各项服务的标准执行。

| 档位 | 首次响应 | 紧急事项 |
| --- | --- | --- |
| 资讯版 | 1 个工作日内 | 按普通事项处理 |
| 标准版 | 工作时间 2 小时内 | 当日处理 |
| 顾问版 | 工作时间 1 小时内，优先处理 | 可直接电话联系 |

**服务渠道**

- **主渠道：** 顾问的企业微信，老板用自己的微信即可对话。
- **辅助渠道：** 电话、面谈；文件可通过微信发送或使用共享文件夹。

**服务节奏**

| 频率 | 内容 |
| --- | --- |
| 实时 | 机会与风险提醒，没有要紧事不打扰 |
| 每周一 | 行业资讯、本周待办、本周一问 |
| 每月初 | 月度复盘与价值账单 |
| 每季度 | 面对面复诊（标准版）；顾问版为每月会议 |

**数据原则：** 不要求上交全部数据，不跨企业共享原始数据，不默认读取敏感数据，未经授权不扩大用途；企业退出后 7 天内删除其全部数据。

## 二、基础服务（三档均包含）

四项基础服务不依赖企业提供经营数据，签约第一周即可开始。

### 2.1 首次经营体检

| 项目 | 说明 |
| --- | --- |
| 服务内容 | 90 分钟老板访谈；收集基本信息、近期困扰和可提供的资料；整理外部政策与行业机会；建立企业健康档案 |
| 交付物 | 一页纸健康评分卡（红黄绿）、主要问题与机会清单、30 天行动建议；企业提供销售、应收或库存数据时，附完整初诊报告 |
| 服务标准 | 访谈后 5 个工作日内交付；至少指出一个具体的问题或机会；数字须标明来源；数据缺口单独列出 |
| 服务方式 | 面谈或视频访谈；报告通过微信发送，并约 30 分钟解读 |

### 2.2 每周行业资讯

| 项目 | 说明 |
| --- | --- |
| 服务内容 | 政策补贴、招投标、上游调价、本地商业变化、监管通报、文旅客流等与企业相关的信息 |
| 服务标准 | 每周一上午发送；每期 3–5 条；每条都写明“对你意味着什么”和“可以怎么做”；附原文链接；涉及金额、日期、条件的内容须人工核实；当周没有相关信息时如实说明，不凑数 |
| 服务方式 | AI 按行业信息源库采集和初筛，顾问按企业档案筛选、解读并发送 |

### 2.3 关键日期提醒

| 项目 | 说明 |
| --- | --- |
| 服务内容 | 企业年报、报税申报、证照与健康证到期、合同与租约到期、设备保养、节假日备货等 |
| 服务标准 | 建档时一次性整理；按事项提前 7–30 天提醒；到期后跟进是否完成 |
| 服务方式 | 推送到老板手机日历或企业微信日程，使用本地工具提醒，不另装软件 |

### 2.4 本周一问与经营档案

| 项目 | 说明 |
| --- | --- |
| 服务内容 | 每周随资讯提出 1–3 个简单问题，例如生意好坏、客户变化、近期打算 |
| 服务标准 | 问题能用一句话或一条语音回答；回答在 2 个工作日内整理进经营档案；不追问老板不愿回答的问题 |
| 服务方式 | 微信文字或语音，AI 转写整理，顾问确认后存档 |

## 三、问诊与材料服务

问诊解决“有个问题想问问”，材料服务解决“有个东西要写”；两者按工作量分级，超出额度的部分用次卡或单独报价。

### 3.1 问诊

| 项目 | 说明 |
| --- | --- |
| 服务内容 | 单次处理时间在 30 分钟以内的经营问题：定价、促销、招聘、客户处理、政策解读、要不要做某件事 |
| 额度 | 资讯版：文字简答；标准版：每月 5 次；顾问版：不限次 |
| 服务标准 | 按档位时效首次响应；简单问题当日答复，需要查资料的 2 个工作日内答复；答复包括结论、理由和建议的下一步 |
| 服务方式 | 微信文字或语音；复杂问题约 15 分钟电话 |
| 超出处理 | 预计超过 30 分钟的问题，先告知老板转为材料服务或专项服务，经同意后再做 |

### 3.2 材料服务

| 级别 | 示例 | 交付时限 | 资讯版 | 标准版 | 顾问版 |
| --- | --- | --- | --- | --- | --- |
| 轻 | 文案、差评回复、通知、海报文字、招聘短启事 | 1 个工作日 | 每月 2 份 | 合理用量内不限 | 合理用量内不限 |
| 中 | 活动方案、招聘方案、员工手册单章、合同审阅要点 | 3 个工作日 | 次卡 | 每月 1 份 | 每月 4 份 |
| 重 | 申报材料、商业计划书、完整制度、投标文件 | 按项目约定 | 单独报价 | 单独报价，九折 | 单独报价，八五折 |

**材料服务标准**

- 动笔前确认用途、读者和关键信息，避免返工
- 每份材料包含 1 次免费修改；超出的修改按新需求处理
- 内容中的事实、数字和政策条款须标明来源，由老板确认后再对外使用
- 合同审阅只列出风险点和需要注意的条款，不替代律师意见
- 材料交付后归入企业档案，下次同类需求可直接复用

## 四、服务资源推荐与企业数据分析

### 4.1 服务资源推荐

帮老板在凯里找到靠谱的人和资源，是“家庭医生”定位中最难被替代的部分。

| 项目 | 说明 |
| --- | --- |
| 资源范围 | 政府免费资源（政务服务、培训、补贴、融资对接）；专业服务（代账、律师、知识产权、人力资源）；经营服务（设计、装修、摄影、维修、招聘渠道）；本地供应链；协会会员之间的供需 |
| 服务流程 | 识别需求，推荐 2–3 家并说明各自特点与大致价格，由老板自行选择，一周后跟进结果并记录评价 |
| 服务标准 | 只推荐经过实际使用或老客户评价良好的资源；明确告知哪些推荐有转介收益；评价差的服务商移出资源库 |
| 档位差异 | 资讯版：推荐；标准版：推荐并跟进结果；顾问版：推荐并陪同对接 |
| 会员权益 | 争取合作服务商为会员提供专属价格 |

### 4.2 企业数据分析（企业提供数据时）

本项为可选服务：企业愿意提供数据就做，不提供也不影响其他服务。

| 项目 | 说明 |
| --- | --- |
| 可用数据 | Excel 或 CSV 台账、美团和抖音等平台后台导出、收银系统导出、进销存导出、手写记录的照片 |
| 分析内容 | 销售趋势、产品与客户结构、应收账龄、库存库龄、异常变化 |
| 服务标准 | 所有数字由程序计算，可追溯到原始文件；收到数据后 3 个工作日内完成；结论与建议经顾问审核 |
| 档位差异 | 资讯版：不含；标准版：月度简析；顾问版：月度深度分析 |
| 服务方式 | 老板通过微信发送文件，顾问整理后随周报或月度复盘一起反馈 |

## 五、面对面服务与月度复盘

### 5.1 面对面服务

| 项目 | 标准版：季度复诊 | 顾问版：月度会议 |
| --- | --- | --- |
| 频率与时长 | 每季度 1 次，约 60 分钟 | 每月 1 次，约 90 分钟 |
| 内容 | 回顾三个月的变化、行动完成情况，确定下季度重点 | 经营回顾、重大决策讨论、专项分析汇报、下月重点 |
| 会前准备 | 提前 2 个工作日发送议程和要讨论的问题 | 提前 3 个工作日发送议程和资料 |
| 会后交付 | 1 个工作日内发送纪要与待办 | 1 个工作日内发送纪要、待办和负责人 |
| 方式 | 到店或约在附近面谈，特殊情况可视频 | 到店面谈为主 |

### 5.2 月度复盘与价值账单（三档均包含）

| 项目 | 说明 |
| --- | --- |
| 服务内容 | 本月发生的重要事件、做出的决定和结果；本月提供的资讯、问诊、材料和推荐；帮企业获得或节省的金额；服务按市场价折算的价值 |
| 服务标准 | 每月前 5 个工作日内发送；一页以内；金额只写有依据的，估算须注明；周报中不推销，升级建议只在价值账单中出现 |
| 服务方式 | 微信发送图文或 PDF；老板有疑问时约 15 分钟电话 |

## 六、增值服务

增值服务按项目单独签约，会员享受折扣；所有项目在开始前书面确认范围、交付物、时间和费用。

| 服务 | 内容 | 服务标准 | 收费方式 |
| --- | --- | --- | --- |
| 政策申报代办 | 条件核对、材料准备、填报辅导、进度跟踪 | 先做条件核对，判断不符合的直接告知，不收费；申报节点提前提醒 | 基础费加成功费，成功费按获批金额提成 |
| 专项经营诊断 | 针对单一问题的深入分析，如门店盈亏、产品结构、渠道效果 | 10 个工作日内交付报告并面谈解读；结论附数据依据 | 按次，2000–5000 元；优先争取政府付费 |
| AI 与数字化项目 | 企业微信客户管理、知识库、AI 工作流、报表体系 | 标准化套餐，固定价格；交付后提供使用培训和 30 天答疑 | 按套餐，3000–30000 元 |
| 专项咨询 | 开店选址、业务转型、组织调整等 | 开始前确认目标和交付物；按约定节点汇报 | 按天或按项目 |
| 专科转诊 | 财税、法律、人力、融资、知识产权等问题对接专业机构 | 说明转介原因并推荐 2–3 家；跟进处理结果；本项目不替代专业意见 | 客户不加价，由合作机构支付转介费并向客户公开 |
| 资源撮合 | 客户、供应商、合作伙伴的对接 | 双方同意后才介绍；跟进对接结果 | 早期免费，成交后再约定收费 |

## 七、服务边界与质量保障

### 7.1 不提供的服务

- 不代替企业做经营决策，建议由老板自行判断和决定
- 不提供法律意见、税务筹划、审计或会计记账，相关需求转介专业机构
- 不代为操作企业的资金、账户和平台后台
- 不承诺具体的增收、获批或回款结果
- 不承接与经营无关的个人事务

### 7.2 质量保障

| 环节 | 保障措施 |
| --- | --- |
| 内容审核 | 所有发给企业的内容由顾问审核后发出，AI 只负责收集、整理和初稿 |
| 信息准确 | 政策、招标、金额、日期须核对原文并附链接 |
| 防止发错 | 每家企业独立档案；发送前核对收件企业 |
| 时效追踪 | 记录每次响应和交付时间，每月自查达标率 |
| 客户反馈 | 每月复盘时请老板对服务打分，低于期望的事项下月优先改进 |
| 服务补偿 | 当月响应或交付时效未达标超过 2 次，下月赠送 1 次中等材料或 1 次问诊 |

### 7.3 AI 使用说明

服务中使用 AI 辅助完成信息收集、数据整理和初稿撰写；企业数据只传入经过处理的必要信息，不上传原始文件，使用国内模型，数据不出境。老板可以随时询问某项内容的来源和形成过程。
