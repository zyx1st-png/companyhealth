# H01｜双线单客经济与人工容量统一口径 V1.0

**性质：核算定义，不是实际盈利报告。** 现有H02表格是预算假设载体，C02是会员现金及工时情景；本文件统一两条业务线的会计和管理指标。不得根据单一情景宣称利润。

## 1. 三套独立账

1. **现金账**：实际收到的客户服务款、实际退款、税费及已经实际支付的工具、差旅、外包等，区分固定与增量现金。时间窗口、发票和到账时点记清。
2. **容量账**：创始人、顾问人工分钟；分获客/访谈、首次建档、共享研究、每企交付、客户交互、报告审核、返工、协会公益、专项执行及内部管理。允许共享时间按事先规则分摊，但不重复计数。
3. **组织复制账**：假设雇员/外包替代的合理人工成本、管理成本和质量监控，单独报告，不混入没有实际发薪的现金账。

合同额≠到账额≠当期履约收入≠利润。预收多月会员费须与未来交付义务分开展示；新客户取消99元体验，不再存在新客体验收费或抵扣；旧口径仅按实际历史合同/票据处理，不得虚列收入。

## 2. 首轮30天双线均衡时间口径（作者已确认B）

首30天不采用“销售20小时、会员服务65小时”作为各线专属分配，而以**85小时双线经营池=会员M42.5小时+专项P42.5小时**为内部排期假设；公共技术20、运营/合规15、协会公益**上限12**小时单列，合计仍为原F02的132小时/月计划，不代表实际工时。每条线都必须包含自身获客、免费访谈、建档/交付、审核/返工、真实会议与差旅。原65小时会员服务**不得重复加回**。

实际分析以V01分钟台账为准；若有真实交付高峰，先履行合同与安全义务，偏离50:50需记录，**不得平均分摊伪造实际工时**。公共工时可用于管理成本分摊分析，但实际劳动时间只能记一次。首30天为暂定分配，D30复盘后作者才决定后60天。详见V02。

## 3. M会员线

**2026-10-13新口径**：免费M-L0交付不得计作现金收入。B06额度按每周、快办:定制为2:1折算：199最多2轻/1复杂；399最多4轻/2复杂；1299最多6轻/3复杂。每档任务要记录小型对外成果、实际人工分钟、模型调用与返工；跟定期周报/问诊/月会区别登记，不能叠加旧材料份数。

统一当前价：199/399/1299元起，基础年付1980元。C02暂估固定现金1298元/月及增量现金5/10/30元/家/月，均是**未实测参数**。

单客记录：
- **获客工时**：初次接触、访谈、跟进、报价（渠道引荐公益时间单列）。
- **启动成本**：免费M-L0接触、最小建档、机会简报、1次轻量快办、短期信息跟进及正式会员入职；旧D01按99元付费体验估算5.5–12.5小时已不适用于新客，应重新实测。
- **稳态维护**：每周报告、月简析、问诊材料、现场拜访/响应排班、行动跟进。
- **共享成本**：公共信息核实、模板维护、计算程序运行；分摊原则应事先记录。
- **异常成本**：资料清洗、错误更正、客户临时高密度需求、重新送审、退款。

每档按**普通使用、充分使用权益、请求集中峰值**至少三种场景估计工时，尤其399元正式权益已改为每周2复杂或4轻量事务，加约5次问诊、周期简报、月度简析及季度复诊；不能与旧每月1份中等材料重复计算，也不能只采用C02旧“基准1.5小时”就宣称可服务50家。

## 4. P高级专项线

每项目必须登记：P-L0免费初筛与其他售前分钟、单独报价金额、合同金额、首款/进度款/尾款实际到账、数据准备、分析核验、交付、返工、客户会议、差旅、外包、客户授权资料处置、验收日期。

P01的18–35小时与3800–8800元只是内部拟议区间；P03/P04复杂项目须拆范围、里程碑与专业责任。高客单价不是天然高利润，必须核算项目实际工作量和未收尾款。

## 5. 双线并行的正确汇总

- 同一企业既买M又买P：**独立合同/订单/工时项目号**；企业去重后才统计“唯一客户数”。
- 商协会项目、公益投入、推荐线索分别计数；不以协会会员规模计算M月度付费客户。
- 资源对接或项目机会未经成交、未形成可核实收费权，不计收入。
- 使用同一套AI订阅：固定费用不重复按客户扣；额外调用按实际增量发生记录。
- 共同程序改进与模板建设计入共享研发工时，不随意归零；决策是否扩张时需考虑未来维护。
- 记录未到付款/续约/验收节点，不作为违约或流失。

## 6. 最小90天管理看板

每周：M有效线索/免费M-L0启动与完成/首次实际使用/正式会员实收及续费；P有效问题/报价/合同/首款/验收；M/P分轨人工小时；重大交付错误；实际支出和软件调用。第30/60/90天通过V00/V01审查。

**红线**：在没有真实客户及完整分母前，所有毛利率、续费率、CAC、LTV、50家利润与T01效率都只能标“假设/尚无数据”。更换假设前保留旧版本及证据原因。
