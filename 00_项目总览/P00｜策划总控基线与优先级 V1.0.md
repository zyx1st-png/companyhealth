## 1. 一句话定位与双线结构

品牌主张：**中小企业的经营家庭医生——AI负责持续观察和辅助整理，顾问负责判断、核实、行动跟进与服务责任。**

真正销售的不是AI生成的文本，而是**发现具体经营问题 → 建立证据 → 形成行动 → 持续跟进结果**。

- **M 会员线**：99元/30天体验 → 199/399/1299元起月费三档；主要验证持续使用与续费。依据 A02、B01、B02、D01、D02、F01。
- **P 高级专项线**：L0免费15–30分钟初筛 → P01–P04独立项目 → 可选P05陪跑；主要验证问题驱动的高价值成交和可控交付。依据 B08、B08-EXT、BP V0.4。
- 两条线**并行验证、不预设赢家**；可同客户分别购买，但合同、范围、收入与工时分别核算。不能将P01–P04完整交付当作399或1299元会员权益，也不能将99元体验视为高级专项必经入口。
- 协会是**可选渠道/可讨论的机构客户**，不是已经确认的收入、企业名单或商业资产。公益与收费、协会数据与独立客户数据分开（C03、C03-INT）。

## 3. 文件冲突时如何处理

1. **已经签订的合法有效合同与明确授权优先于内部策划**；不能通过仓库改文档单方面削减现有客户权益。拟议合同须律师和实际签约主体确认。
2. 产品价格与权益：**B02 V1.1（服务细则） + B01（价目） + B08（专项范围）**；C06为展示/报价草稿；对外签署前逐项确认。
3. 战略：**商业计划书 V0.4 + 本P00**；会员Go/No-Go遵F01；专项Go/No-Go遵B08；整合看V00。C02只解释会员单位经济，不替代双线战略。
4. 执行：D01/D02管会员体验，B08管高级专项，D04管会员SOP，T01管技术实验；不得将各自样本或成果相加声称同类证据。
5. 技术：**T00当前分期验收 + MVP现行范围 + T02安全修订**。若细节仍冲突，优先更严格的安全边界并登记待决，不由AI自行扩大授权。
6. **历史情景、总目录中早期规划条目、_archive文件和“方案多维分析”不得覆盖上述现行口径。**

## 4. 已裁决：首轮30天双线均衡投入（选择B）

**作者2026-10-12裁决**：首轮30天会员M、高级专项P**均衡推进**，不是整个90天永久平均。依据F02的132小时/月假设，把原“销售20小时+会员服务65小时”调整成**85小时双线经营时间池**，M/P各42.5小时；AI/技术20、运营及合规15、协会公益上限12小时单列，原总规划容量不变。此为规划工时而非已经实际发生；公益上限不是必须使用，公共工时不得重复计入两线。

会员M优先分批2–3家合规付费体验和真实服务；专项P优先约2–4次有效L0初筛、争取1–2份范围明确的正式报价，签约/首款/验收按真实节点分别记证据。**不能要求两线成交额或客户数量相同**。已签合同、安全和人工服务承诺优先，时间偏差记录后暂停新增超容量承诺，不得单方减少原客户权益。

**本决策只冻结首30天时间方向，不增加1298元固定现金预算，不提前裁决Q2抵扣期限、Q4签约主体或Q5技术入口。** 第30天依据V01证据另裁决后60天的配比。具体逐周任务和停止条件以 `04_真实验证与决策/V02｜首轮30天双线均衡执行计划 V1.0.md` 为准。

## 5. 决策优先级：先降低哪种不确定性

**P0（立即）**：确定可合法收费的服务主体/对外条款；准备2–3家会员体验；争取P01/P03/P04的明确问题线索；用V01记付款与工时；先建立手工闭环。

**P1（首30天）**：做首次体检和行动跟进；获取至少一次正式专项报价反馈；以真实流程测试资料分隔、计算与审核；按工时决定下一步开发。

**P2（第31–60天）**：检查会员转正、真实活跃及专业项目签约/交付；执行T01分离对照，不将周报效率等同于全会员容量。

**P3（第61–90天）**：分别裁决M线、P线和技术扩张（Go/Adjust/No-Go）。允许“会员不成立、专项成立”或反过来，不采用统一真假二值结论。
