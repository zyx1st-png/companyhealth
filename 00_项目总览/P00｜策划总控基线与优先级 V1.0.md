## 1. 一句话定位与双线结构

品牌主张：**中小企业的经营家庭医生——AI负责持续观察和辅助整理，顾问负责判断、核实、行动跟进与服务责任。**

真正销售的不是AI生成的文本，而是**发现具体经营问题 → 建立证据 → 形成行动 → 持续跟进结果**。

- **M 会员线**：M-L0免费轻量预服务（7–14天，首轮轻访谈/最小建档/外部机会简报/1–2次信息跟进/有限问询及1次轻量事务体验）→ 199/399/1299元起正式月费；**取消99元/30天新客体验路径**。依据B01/B02/B06、D02/D06及F01/V02。
- **P 高级专项线**：P-L0免费15–30分钟问题初筛 → P01–P04独立项目 → 可选P05陪跑；与M-L0名称、产出和证据台账严格分开。依据B08、B08-EXT、BP V0.4。
- 两条线**并行验证、不预设赢家**；可同客户分别购买，但合同、范围、收入与工时分别核算。不能将P01–P04完整交付当作399或1299元会员权益，也不强迫P线客户先走M-L0。
- 协会是**可选渠道/可讨论的机构客户**，不是已经确认的收入、企业名单或商业资产。公益与收费、协会数据与独立客户数据分开（C03、C03-INT）。

## 3. 文件冲突时如何处理

1. **已经签订的合法有效合同与明确授权优先于内部策划**；不能通过仓库改文档单方面削减现有客户权益。拟议合同须律师和实际签约主体确认。
2. 产品价格与权益：**B02 V1.1（服务细则） + B01（价目） + B08（专项范围）**；C06为展示/报价草稿；对外签署前逐项确认。
3. 战略：**商业计划书 V0.4 + 本P00**；会员Go/No-Go遵F01；专项Go/No-Go遵B08；整合看V00。C02只解释会员单位经济，不替代双线战略。
4. 执行：D01/D02管会员体验，B08管高级专项，D04管会员SOP，T01管技术实验；不得将各自样本或成果相加声称同类证据。
5. 技术：**T00当前分期验收 + MVP现行范围 + T02安全修订**。若细节仍冲突，优先更严格的安全边界并登记待决，不由AI自行扩大授权。
6. **历史情景、总目录中早期规划条目、_archive文件和“方案多维分析”不得覆盖上述现行口径。**

## 4. 已裁决：首轮30天双线均衡投入（选择B）

**作者2026-10-12裁决**：首轮30天会员M、高级专项P**均衡推进**，不是整个90天永久平均。依据F02的132小时/月假设，把原“销售20小时+会员服务65小时”调整成**85小时双线经营时间池**，M/P各42.5小时；AI/技术20、运营及合规15、协会公益上限12小时单列，原总规划容量不变。此为规划工时而非已经实际发生；公益上限不是必须使用，公共工时不得重复计入两线。

## 5. 决策优先级：先降低哪种不确定性

**P0（立即）**：确定可合法收费的服务主体/对外条款；准备3–5家自愿免费M-L0；争取P01/P03/P04的明确问题线索；用V01记付款与工时；先建立手工闭环。
