# C08｜双线销售分流与报价边界 V1.0

**内部SOP；不是独立对外报价单。** 对外最终展示依C06、B08正式范围和签约主体审定结果。所有价格仅为现行设计/内部测试价。

## 1. 第一次接触只判断：老板目前要解决什么

问四个问题：①最近3个月最困扰的经营问题是什么；②该问题不解决会造成什么影响，是否有决定期限；③负责人是否愿意配合最小数据和访谈；④采购决策者是谁、是否曾为同类问题付费。记录原话，不先介绍Agent架构。

## 2. 分流规则（同一个客户可同时属于两线，但分开报价）

| 观察事实 | 推荐入口 | 不该做的事 |
|---|---|---|
| 没有单项重大问题，愿意定期被关注、持续问答 | M：99元/30天体验 | 不免费承诺完整体检或不封顶顾问 |
| 有单项明确决策/现金/渠道/利润问题，决策人愿意了解付费 | P：L0免费15–30分钟初筛，再报P01 | 不把P01硬塞进99或399元 |
| 已明确下一步实施任务且范围可核实 | P02 | 不跳过基线、验收和责任边界 |
| 正在筹备新店、样板、扩张决策 | P03 | 不保证盈利、开业或政策审批 |
| 重复数据、报表、跨人协作瓶颈，有明确流程 | P04 | 不承诺未验证的自动微信读取/发送接口 |
| 想长期有外部顾问参与特定议题 | 比较1299顾问版与P05专项陪跑，先列权益与工时差异 | 不卖两个几乎相同的付费承诺 |
| 只需要律师/税务/审计法定意见 | 有资质伙伴独立对接 | 不以AI结论替代法定专业报告 |
| 协会统一服务需求 | C03机构合作另谈 | 不把协会成员直接算作私营付费会员 |

## 3. 三类容易混淆的报价

- **M常规会员权益**：B01+B02限定的问诊、周期服务和材料；399元标准版正式基线每月**1份**中等材料；问诊约5次，响应2小时（工作时间）。
- **会员专项简析**：2000–5000元/次，基于现有企业档案的较窄单一主题，按B02约定输出；不等于完整经营诊断与实施。
- **P01完整专项诊断**：3800–8800元/项内部测试区间；需独立问题定义、补充证据、原因验证、方案取舍、行动计划、解读及验收；不能只因价格区间重叠就承诺同一深度。

B08 P02–P05依B08产品卡报价；对外需**先划定工作单元、交付件、修改轮数、预计工时、外包职责、支付节点**。报价根据范围调整，而不是不加限制打折。

## 4. 销售漏斗和可追溯证据

**分别建立两套漏斗：**

- M：有效接触 → 深访/筛选 → 99元付费 → 30天服务 → 正式购买 → 到期续费 → 真实使用与行动。
- P：问题线索 → 有效L0初筛 → 书面范围 → 正式报价 → 合同与首款 → 交付验收 → 尾款 → 后续复购或会员（另记）。

不得把“99元订单”计为“399元月度稳定收入”，把“合同额”当“到账额”，把“转介见面”当“付费项目”，也不得把同一个客户的P项目和M合同人数重复计算为两家企业。

拒绝与未成交必须记录原因：无明确痛点、没有预算、资料无法获取、专业责任不匹配、不信任、价位不符、时机不对、其他。只记录脱敏标签与汇总指标到仓库。

## 5. 一次沟通后的最小输出

记录：线索代号、行业、直接/协会/转介来源、问题原话（敏感内容不上Git）、影响及期限、决策人是否参与、拟走M或P、提出的下一步、初筛实际耗时、成交状态、拒绝原因。

提供下一步时必须具体：如“预约15分钟资料清单确认”、“书面列出P01边界及报价”，而不是模糊的“以后有机会合作”。

## 6. 治理与合规

无合法收款与签约条件时不收商业服务费；无G03合格授权时不接收B/C类客户资料。C06仅作为草稿，需要核验G00–G07、价格、第三方关系和主体后方能对外发送。协会公益互动与商业获客分界遵C03-INT，不暗示协会背书或默认开放名单。
