# C08｜双线销售分流与报价边界 V1.0（2026-10-13修订）

**2026-10-13作者新产品路径（内部SOP）**：新客取消99元/30天体验。会员M线以免费M-L0（7–14天）预服务开启；专项P线仍使用独立的P-L0 15–30分钟免费初筛；不得仅以“L0”混写两种不同服务。具体范围参见D06/B06，收费与合规要求以G00/G10为准。

## 1. 第一次接触目标

理解企业的产品/服务、当前客户与渠道、近期困扰、愿意自愿谈及的资料，以及是否愿意接收针对性公开市场信息。先提供一次轻价值，不以销售压力强迫提供内部利润、合同或完整账目；也不把对方一句认可记录为订单。涉及直接收费的P专项，则需确认决策者、问题影响、期限、预算与可合法取得的证据。

## 2. 两条线的入口与分流

| 观察事实 | 合适入口 | 不该做的事 |
|---|---|---|
| 只愿初步交流、接受个性化外部信息、可能有日常需求 | **M-L0**：一次轻交流/最小建档/外部机会简报/一次快办/短期跟进 | 不强要数据；不超期无限免费 |
| 已经认可持续经营事务支持，愿意为月度服务付费 | **M会员199/399/1299元起** | 不要求先买取消的99元档；不把材料额度叠加 |
| 明确一个重要经营问题且愿意讨论专项预算 | **P-L0**免费15–30分钟初筛→P01等专项书面报价 | 不把完整诊断塞进免费M-L0或399会员 |
| 已明确实施任务与验收范围 | P02；新店样板/扩张P03；数据流程P04 | 不承诺未验证的自动微信读取/发送及实施结果 |
| 想长期外部顾问参与 | 对比M顾问会员1299起与P05专题陪跑 | 列清范围与工时，避免重复收费 |
| 只需法定专业意见 | 相应持牌伙伴另行承接 | 不让AI摘要冒充法律税务审计结论 |
| 协会机构统一合作 | C03/C03-INT机构路径 | 不把协会成员名单、公益服务或协会背书自动算商业合同 |

## 3. M会员对外交付定位

| 档位 | 会员月价 | 日常快办与定制处理（每周互替、不叠加） | 核心增量 |
|---|---:|---|---|
| 基础 | 199元 | 3轻量或1复杂 | 有人持续关注经营信息并协助日常事务 |
| 标准 | 399元 | 6轻量或2复杂 | 更多问诊、经营简报、月度简析与问题跟进 |
| 顾问 | 1299元起 | 9轻量或3复杂 | 顾问会议、深度经营分析与优先协助 |

1复杂替代3轻量，可混用；周额度和修改边界见B06，不再沿用旧中等/轻材料月度附加份数。对外强调C09中具体常见服务，不以“AIGC次数”为卖点。营销宣传不等于免除AI处理资料时的必要告知。

## 4. 销售与证据漏斗

- **M**：合法自愿接触 → 免费M-L0说明与授权 → 有效访谈/建档/轻量实际交付 → 7–14天实际使用/反馈 → 正式月费书面报价 → 成交并实收/未成交原因 → 正式交付 → 续费。
- **P**：具体问题线索 → P-L0免费初筛 → 明确工作范围 → 正式书面报价 → 合同及首款 → 交付验收 → 复购或会员（另记）。

不把免费M-L0、转介绍见面、服务被称赞、书面报价当成真实付款；不把同一企业分别购买P项目和M会员累计为两家企业。跟踪转化分母、人工工时、客户主动问询、客户实际使用以及付费后的续费；合同额与实收额分开。

## 5. 沟通后的最小记录与合规

内部只存匿名企业代号、渠道、同意与接触日期、一次访谈/初简报/快办是否完成、反馈和下一步、M/P分线、实际耗时、报价及支付状态（脱敏）。原始聊天、个人资料、敏感财务与完整业务合同不上Git。无合法签约主体/报价说明时不收费；尚未取得明确授权时不收集B/C类企业资料。协会公益与收费客户严格分开。
