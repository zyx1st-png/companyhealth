# C09｜企业经营日常助手（对外服务说明草稿）V0.1

**服务说明草稿：待企业试读及正式服务条款审核，签约时以双方确认的合同和权益附件为准。**

## 经营有信息需要关注，日常有事情需要处理，都可以和我们说

为中小企业持续关注行业与政策、经营事项和实际问题，同时协助完成日常文字、宣传、办公及经营材料。你可以通过微信用文字或语音说出需求；我们先确认要做成什么，再按范围交付。我们不是来替代企业管理层做决策的。

## 平时可以帮你做什么

| 经营场景 | 日常快办：简单、明确的小事 | 定制处理：需要整理与构思的小型工作 |
|---|---|---|
| 宣传、活动 | 朋友圈文案、简单海报、活动通知 | 一组活动宣传图文、短视频脚本和分镜 |
| 客户、销售 | 客户回复、报价说明、邀约话术 | 产品推介资料、销售答疑整理 |
| 办公、会议 | 通知、会议议程、文字润色 | 根据现成资料整理纪要及行动清单，或用既有模板制作简短演示材料 |
| 招聘、培训 | 招聘信息、员工公告 | 岗位说明、简单培训资料 |
| 经营问题 | 梳理一个问题、列两个选择的利弊 | 单项问题初步分析、小型活动测算 |
| 市场、政策 | 一份已有资料的要点、公开政策基础解读 | 根据企业提供且已核实的资料整理简短市场摘要或产品对比；需额外调研另行报价 |
| 采购、合作 | 采购清单、合作邀约 | 现有报价对比、合作介绍初稿 |
| 表格、数据 | 整理清单和已有表格、解释单一数字 | 基于企业已整理的简单表格作核算、图表与说明；大量清洗另议 |
| 知识、流程 | 操作说明、问题答疑 | 简单流程手册、产品知识资料 |

只在必要时要求你提供资料；涉及事实、数字、政策及对外承诺，会说明待确认内容。是否属于套餐内小型工作，以交付前双方明确的范围为准。

## 两种服务，简单好懂

- **日常快办**：一个明确的小问题，快速整理成一项简单成果，例如一条文案、一张模板图、一份通知、一个资料摘要。
- **定制处理**：需要综合一些资料和思路，完成一项小型成果，例如简短PPT、宣传图文小包、单项情况对比、简单活动方案。

| 套餐 | 月费 | 每周可选服务量（两列替代，不相加） |
|---|---:|---|
| 基础会员 | 199元 | 1次定制处理 **或** 3次日常快办 |
| 标准会员 | 399元 | 2次定制处理 **或** 6次日常快办 |
| 顾问会员 | 1299元起 | 3次定制处理 **或** 9次日常快办 |

1次定制处理等于3次日常快办，可混用；每项含一次同方向合理修改，超过约定范围先商量。未使用次数不累积到下周。复杂专项方案、完整视频、全套品牌设计、法定专业意见、持续代运营另行评估。

**还有持续经营支持**：**三档均提供每周相关信息/机会/风险与待办简报**，基础版附事项提醒与简单问答；标准版升级为结合企业资料的经营健康简报、月度简析及经营问诊；顾问版进一步提供更深入的经营分析、顾问会议及重要事项支持。具体深度、时效与签约范围以书面服务说明为准。

## 免费认识一下

可通过朋友或协会自愿引荐参加一次7–14天的轻量体验：简单沟通、基础建档、一份公开信息机会简报、少量后续信息/问询，**再免费试做1项日常快办**。结束后自主决定是否购买月度服务，不设置99元付费体验档，也不默认续费。

**服务不是一定能代替专家或保证收益**：法律、税务、审计意见由相应专业人士负责；经营建议需结合企业自身判断；资料使用范围与AI辅助处理方式会另行说明。

**次数与问答不重复计算**：原本约定的每周简报、重要事项提醒，以及微信对话中直接回复的基础经营问题，不扣上表日常任务次数；如果另外要求制作独立PPT、表格、图文、正式材料等交付物，提前确认按一次快办还是一次定制计算。首次经营了解按基础简版画像、标准重点访谈、顾问深入议题分层，免费体验不包含完整体检。
