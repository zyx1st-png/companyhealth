# G10｜收费签约与数据合规启动核验 V0.1

**性质：内部核验表，非法律意见或可直接使用的合同。** G00–G07仍是草稿，应由执业律师及财税专业人员结合服务主体、地区、客户数据与实际交易审定。

## 首次签真实客户之前

- [ ] 已明确合法经营、签约、收款与开票主体；未经授权不借用其他主体公章/账户。
- [ ] 会员体验使用G01与附件，专项使用G01-B及对应的详细范围确认与附件；核验合同主体、交付清单、付款节点、退款/违约处理。
- [ ] 体验99元是服务费而非意向金；完成约定履约后不因不转正退款，法定退款另行依法处理；不自动续费。
- [ ] **G01草稿“结束后30日抵扣”仍待裁决**；在作者及律师确认并对齐A02/D02/C06之前，不将这一新增期限作为对外已经确定的限制。
- [ ] 客户数据G03分级授权和G05 AI处理告知实际签署；不因签一张通用授权就无限扩大用途。
- [ ] 核验外部模型服务条款、存储位置、供应商或专业机构可接触资料的范围；客户敏感资料未经许可不发第三方。
- [ ] G06退出、返还/删除、备份轮换的建议期限经律师确认；保存必要财税与争议记录不等于保存全部原始客户资料。
- [ ] 说明不提供法定审计、法律、税务、专项许可等须资格服务；由适格主体独立负责。
- [ ] 明确真实响应人员可保障合同承诺，不将自动回执算成人工首次回复。
- [ ] 核实PPT/PDF/报价单是否与现行双线、权益、价格、退款和案例属性一致。
- [ ] 对外使用的案例已得到相应许可；没有许可时只能用明确标注的模拟或公开信息分析。

## 何时补其他合同

G02**正式会员协议**：首个会员转正签约前完成；G08**资源转介协议**：首笔转介费用承诺前完成；G09**协会合作协议**：协会采购、共同服务或成果共建开始前完成。未完成时不以口头理解代替书面权责。

## 事故止损

客户归属、原始数字、数据授权、敏感外传若出现严重错误，暂停受影响服务并记录事件、隔离范围、纠正、复测和客户依法应得通知；不要仅为了试点进度继续发送。
