> **草稿，须经律师审核后使用。** 依据 D04 14.1–14.4 与 15.2、T02 20.4（按资料类别分别处理，替代旧 MVP“退出后统一7日删除”的口径）。本文件作为 G01 / G01-B 的附件。
>
> 文中标“建议值”的期限为起草时提出，无现有文档出处，须确认。

## 一、资料分类

| 类别 | 内容 | 存放位置（D04 14.1） |
| --- | --- | --- |
| ① 原始资料 | 客户提供的文件、截图、导出数据、系统只读访问所得 | 原始资料 |
| ② 分析底稿 | 清洗后的数据、计算表、证据卡、AI 中间稿 | 分析底稿 |
| ③ 正式交付物 | 已发送给客户的报告、简报、方案、模型 | 正式交付 |
| ④ 服务与财务记录 | 合同、授权书、收款与开票记录、服务工单、工时记录、沟通纪要 | 授权与协议 / 服务记录 / 财务记录 |
| ⑤ 去标识化统计 | 不可识别具体企业的工时、使用率等汇总数据 | 内部运营统计 |

## 二、服务期间的保存

1. 每家企业独立编号、独立存储，不与其他企业混放。
2. 原始资料只读保存，不做修改。
3. 每日加密备份；备份介质同样加密。
4. 甲方可随时要求查看乙方保存的资料清单。

## 三、退出时的处理

合同到期不续、提前终止或甲方撤回授权时，乙方按下表处理，并在完成后向甲方发送《资料处置确认单》。

| 类别 | 处理方式 | 期限（建议值） |
| --- | --- | --- |
| ① 原始资料 | 按甲方选择：返还或删除 | 退出后 **10个工作日内** |
| ② 分析底稿 | 删除 | 退出后 **10个工作日内** |
| ③ 正式交付物 | 甲方已持有；乙方留存副本按甲方选择：删除，或保留至【1】年后删除 | 按甲方选择 |
| ④ 服务与财务记录 | 依法律法规及财税要求保存必要记录，到期删除 | 依法定期限 |
| ⑤ 去标识化统计 | 可保留，用于改进服务 | — |
| 备份 | 在备份轮换中清除 | 不超过 **30日** |
| 系统访问权限 | 撤销乙方的所有访问权限，甲方修改相关密码 | 退出当日 |

**默认：** 甲方未作选择的，①按删除处理，③乙方副本保留【1】年后删除。

## 五、甲方的权利

甲方可随时：查询乙方保存了哪些资料；要求更正错误资料；要求删除不再需要的资料；撤回授权（见 G03 第五条）。乙方在【5】个工作日内答复。

## 六、错发、泄露等事件

发生疑似错发或泄露时，乙方：

1. 立即停止传播，采取撤回、隔离或限制访问等措施；
2. 记录事件经过与受影响范围；
3. 在【24小时】内告知受影响的企业；
4. 评估是否需要依法通知相关个人或主管部门，并依法履行；
5. 采取补救与预防措施，必要时寻求专业法律和安全支持。

具体通知义务与时限，依事件情况和适用法规判断（D04 15.2）。
